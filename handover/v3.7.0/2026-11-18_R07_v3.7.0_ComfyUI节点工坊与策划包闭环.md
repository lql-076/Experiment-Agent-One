## 这一轮做了什么

把 v3.6 的四步视频工坊重构成 **ComfyUI 风格的可视化节点工作流**，并补齐硬件状态条、Gemini 策划包导出/导入、生图模型选择、白页/紫苏双角色逐句配音。原有 `img`、`tts`、`bgm`、`publish`、`monitor` 等页面和逻辑保持原样。

### 六个节点

1. **剧本与策划**：主题 / 完整口播；导出 Gemini 策划包；粘贴或上传 `.md` / `.json` 剧本；DeepSeek 一键拆解。
2. **分镜生图**：项目级生图模型下拉、9:16 / 16:9；逐镜画面提示词；生成缺的图 / 全部重出 / 单镜重出。
3. **角色配音**：白页 / 紫苏 / 旁白默认音色；逐句改角色、音色、语气；单句试听与重配。
4. **背景配乐**：Stable Audio 3 提示词、时长、步数；单独生成与试听。
5. **视频合成**：字幕烧录、画幅、配乐闪避音量；单独合成。
6. **成片预览与发布**：`<video>`、封面、送去抖音待确认、打开输出文件夹。

### 画布与执行反馈

- 独立节点卡片 + SVG 贝塞尔连线；空白拖动平移、滚轮缩放、节点标题拖动、一键「居中复位」。
- 外层窗口不滚，画布和节点内部容器滚；横屏 1440×880、竖屏 1080×1860 都是 0 外层滚动。
- 每个节点右上角：状态灯（待命 / 排队 / 运行中 / 已完成 / 出错）、进度条、当前动作、`▶ 只跑本节点`。
- 连线在源/目标节点运行时显示琥珀色流光，完成后变绿。
- 顶部总控：`▶ 从头跑通全流程`、`■ 停下`、新建 / 切换历史项目、居中复位。

### 硬件状态条

- 总控栏下方，每 2 秒 `GET /api/hw`；窗口隐藏时暂停，恢复可见时继续。
- CPU 占用 + 频率（GHz）、内存已用/总量 + %、GPU 占用 + 温度、显存已用/总量 + %；每项带细进度条。
- 复用 `app/hw.py`，和主页/常驻屏同一套数据。

### 固定三合一风格

- 后端 `STYLE_TAG = "知识科普 × 科技数码 × 搞笑段子"`；`PLAN_SYS` 固化「硬核科技科普内核 + 白页 × 紫苏搞笑漫剧冲突」。
- 取消风格单选；项目 `style` 始终写这个标签。
- 65~85 秒、总口播 270~350 字、2 秒钩子、结尾暗号「下期暗号：白页紫苏」。

### 生图选模型

- `state.models` 来自 `imagegen.catalog()`（认识的 + 用 Key 拉过的），前台下拉展示厂商 / 名称 / 价格。
- 选择存 `project.settings.img_model` 和 `uiState.studio.imgModel`；换模型把图标 `stale`、视频标要重新合成。
- 不改生图页的清单；仍调用 `imagegen.card/build_prompt/CALL`。

### 双角色逐句配音

- 分镜字段：`role`（白页 / 紫苏 / 旁白）、`speaker`（音色 ID）、`tone`（百炼语气）、`text`。
- 项目 `settings.role_voices` 存三个角色默认音色；逐句可覆盖。
- 解析顺序：逐句 speaker → 角色默认 → 项目音色。
- `_gen_tts()` 逐句调用 TTS：本地 Qwen3-TTS 用每句 `tone` 作 instruct，百炼用 `synth_once_more()`；本地/云端可混用。每句存 `tts/shotNN.wav`，再拼 `voice.wav` / `subtitles.srt` / `timeline.json`。
- 换角色默认音色时，仍用旧默认的该角色句子一起换掉，并标成要重配。

### Gemini 策划包

- `GET /api/studio/export_prompt_pack`：Markdown 启动包，含固定风格、65~85 秒、2 秒钩子、结尾暗号、白页/紫苏/旁白人设、百炼语气规范（正文不写 `[笑]`）、严格 JSON 字段与 Markdown 备选格式、当前项目主题/标题。
- `POST /api/studio/import_script`：支持 JSON（含代码块）和 Markdown（`## 分镜` + `角色：` / `语气：` / `台词：` / `画面提示词：`）。自动认标题、简介、话题、配乐提示词、角色、语气、台词、画面；缺角色按白页/紫苏交替补。
- 导入后回填节点 ①~④，图/配音/配乐/视频标 `stale`，解析后可直接运行。

### 测试防误覆盖

`dev/serve.sh start` 检测到本机真实 `data/secrets.bin` 时默认拒绝启动（退出码 3）；确实要覆盖必须显式 `AGENT_ALLOW_OVERWRITE_DATA=1`。允许时先备份 `data/secrets.bin` / `settings.json` 到 `dev/.run/data_backup/`，`stop` 自动还原。
