## 这一版做了什么

「视频工坊」从四步流水线升级为 **ComfyUI 风格六节点工作流**：

1. **六节点画布：** 剧本与策划 → 分镜生图 → 角色配音 → 背景配乐 → 视频合成 → 成片预览与发布；SVG 贝塞尔连线、拖动平移/缩放/节点拖动/居中复位；节点状态灯、进度、当前动作、只跑本节点。
2. **硬件状态条：** 2 秒读 `/api/hw`，显示 CPU 占用 + 频率、内存、GPU 占用 + 温度、显存；窗口隐藏暂停。
3. **固定三合一风格：** 知识科普 × 科技数码 × 搞笑段子；65~85 秒、2 秒钩子、结尾暗号「下期暗号：白页紫苏」。
4. **生图选模型：** 节点 ② 可选全部可用模型，存 `project.json` 和 `uiState`；换模型标记图过期。
5. **白页 / 紫苏双角色逐句配音：** 每句 role / speaker / tone，可逐句试听重配；本地 Qwen3-TTS 与百炼云端可混用。
6. **Gemini 策划包闭环：** 导出结构化 `.md`；导入 Gemini 的 `.md` / `.json`，自动回填节点 ①~④。
7. **测试安全锁：** `dev/serve.sh start` 检测到真实 `data/secrets.bin` 默认拒绝启动（退出码 3）；显式 `AGENT_ALLOW_OVERWRITE_DATA=1` 才允许，且备份/还原 data。
