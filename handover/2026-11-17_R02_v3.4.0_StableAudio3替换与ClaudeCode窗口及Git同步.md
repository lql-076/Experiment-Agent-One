## 二、核心架构决策

1. **配乐引擎独立进程 + 独立环境**：`bgm-env` 只装 diffusers / soundfile / lameenc / protobuf，torch 和 transformers 通过 `.pth` 复用 `ai-env`；tts-env 的 transformers 4.57.3 与 diffusers 0.43 的 huggingface-hub 依赖冲突，不能混装。
2. **下载与转换分离**：大权重用 `scripts/fastdl.py` 的 12 连接分段下载（魔搭单连接被限速时从 ~200KB/s 提升到 ~77MB/s）；小文件用 `snapshot_download` 补齐；再用官方 `convert_stable_audio_3.py` 转成 diffusers 格式并写入 `stochastic_sampling=True` 的 8 步调度器。
3. **Windows 无 flash-attn**：不覆盖 SA3 的自定义 `StableAudio3SelfAttnProcessor` / `CrossAttnProcessor`；它们内部走 `dispatch_attention_fn → native 后端 → torch.nn.functional.scaled_dot_product_attention`（SDPA）。显式设置 `DIFFUSERS_ATTN_BACKEND=native`。曾尝试 `AttnProcessor2_0`，会在 `spatial_norm` 上报错，已回退。
4. **蒸馏模型超参固定**：`num_inference_steps=8`、`guidance_scale=1.0`、`negative_prompt=None`、`silence_padding_duration=0.0`、`num_waveforms_per_prompt=1`；44.1kHz 立体声；10~380 秒。
5. **中文描述自适应**：纯中文 + 有 DeepSeek Key + 非隐私 + 非离线时，先转成一句英文音乐提示词；否则原样送 T5Gemma。无 Key/离线时不会阻塞出曲。
6. **Claude Code 工作台**：后端 `_JOB` 保存任务状态，`run()` 仍是聊天里那条执行链；前端 1.2 秒轮询，不用 SSE，和现有界面一致；开关走 `agentkit.set_cap("cc", ...)` 记动作日志；`claude` 子进程一律 `CREATE_NO_WINDOW`。
7. **朗读入口**：对话回复卡片加「朗读」按钮，指令条加「自动念」开关；都调 `/api/voice/speak`，Breeze 没配好自动退回本地配音。顺手补了 `python-multipart`，否则 Breeze 的 FastAPI 服务在启动时直接退出。
8. **Git 零泄露**：路径黑名单 + 内容正则 + 钩子双重拦截；`models/`、`tools/wheels/` 里历史遗留的占位文件从索引删除（磁盘保留），`.gitignore` 彻底忽略；推送只做 fast-forward，绝不强推。

## 三、真机验证结果

### 配乐 Stable Audio 3

- 下载：`model.safetensors` 9,222,116,660 字节（8.59 GiB），`t5gemma-b-b-ul2/model.safetensors` 1,183,022,944 字节；魔搭 fastdl 约 77MB/s。
- 转换：`stable-audio-3-medium`（diffusers）4.9GB；转换 + 安装总用时 249 秒；`model_ok=True`、`B.installed=True`、`_media_ready("bgm")=(True, …)`。
- 服务加载：6.0 秒，`dtype=bfloat16`，`sampling_rate=44100`，RTX 5060 Ti 15.9GB。
- 真实出曲：
  - 10 秒 WAV：44.1kHz / 2 声道 / 441,000 帧 / 1,764,044 字节；服务端出曲约 12 秒。
  - 20 秒 MP3：480,862 字节，MP3 帧头 `fffbb004`；约 22 秒。
  - 新 `app/bgm.py` 连真实服务：10 秒 WAV，12.0 秒，元数据含 `prompt/prompt_en/seconds/duration/took/model/steps/seed/format`。
  - 中文描述自动转英文：`轻快的电子乐，明亮的合成器，适合科技类视频开场` → `Upbeat electronic music, bright synths, tech video intro, uplifting mood, 120 BPM, futuristic digital visuals.`
