## 一句话

视频工坊从「自由节点 + 端口连线」彻底改成 **7 个零连线、全独立可测模块 + Markdown 清单驱动 + 三路并行 + 三窗一体视频总成**。原有生图、配音、配乐、发布等独立页面不动。

## 关键结论

1. **没有端口、没有连线、没有 DAG、没有缺上游**：7 个模块随时单独跑；模块 6 没有配音时自动静音成片。
2. **模块 1 输出 5 份 Markdown 清单**：白页配音、紫苏配音、配乐、视频渲染、生图（可选）。各模块内可直接编辑清单。
3. **生图测试台独立**：全流程跳过，不参与成片。
4. **模块 6 三窗一体**：A 网页动效预览 / B PPT 缩略图 / C FFmpeg 进度与日志，各自「仅重跑」；成片自动进模块 7。
5. **发布仍人工确认**：单条/批量定时清单只入队，不自动发抖音。
