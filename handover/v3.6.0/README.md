## 这一版做了什么

新增「视频工坊」独立工作台（侧栏「视频工坊」/ `?tool=studio`）：

1. **AI 拆解：** 主题或完整口播 → DeepSeek 一次给出分镜口播与语气、逐镜画面提示词、配乐英文提示词、标题与话题。
2. **素材生成：** 生图（复用生图页模型 / 画质，不碰原清单）、配音（本地 Qwen3-TTS / 百炼云端）、配乐（Stable Audio 3）；本地配音和配乐串行，换模型前释放显存。
3. **视频合成：** FFmpeg `zoompan` 推近 / 拉远 / 微移、字幕烧录、配乐 sidechaincompress 闪避、结尾淡出；1080×1920 / 1920×1080；进度实时、可停下、不留半截成片。
4. **预览与发布：** 成片 `<video>`、配音 / 配乐试听、封面；「送去抖音发布」只放进「发布」的待确认队列，点两下才发。
5. **单步重跑：** 只补图、只重配某段、只重做配乐、只重新合成；改台词只让配音和视频过期，改画面只让图和视频过期。
6. **工程结构：** `工作区\视频工坊\<项目名_时间戳>\`（`project.json`、`images`、`tts`、`bgm`、`output`），不进仓库、不进压缩包。

## 重要注意（本机测试副作用）

本机直接跑了 `dev/serve.sh`，它把 `data/secrets.bin` 里的 **DeepSeek / API易 / 百炼三个 Key 写成了假值**。发现后已把服务地址恢复、三个假 Key 清空（QQ Secret / HF Token 没动），测试项目、发布待确认条目、对应配乐历史也已清理。**如果这三个 Key 原来是真 Key，需要到 设置 › 云端 重填一次。** 以后在本机跑 `dev/serve.sh` 前先备份 `data/`，或者只在 Linux 沙箱里跑。
