## 3. 核心架构决策

### 3.1 工程文件是唯一事实

`project.json` 新增：

```json
{"graph": {"nodes": [...], "edges": [...]}, "graph_version": 3}
```

节点带 `id/type/title/x/y/w/h/params/outputs/status/error/cache_key/cache_hit`；产出带相对路径和 SHA-256。旧 `shots[]` 只在兼容旧接口时保留，不再驱动画布。

### 3.2 端口 + 类型 + 环

端口类型：`text / image / audio / video / timeline`。`graph.connect()` 校验：

- 输出端口必须存在、输入端口必须存在；
- 两端类型一致；
- 非 `UNLIMITED` 输入口只接一条；
- 从目标节点顺着连线能否走回源节点（有就是环）。

拒绝时抛出中文原因，接口转 400，界面 toast。

### 3.3 调度

节点一个 `asyncio.Task`，先等所有上游任务，再跑自己；无依赖节点同时开跑。单节点运行前检查每条入边的上游产出，缺就报「缺上游产出」，不自动跑上游。全流程跳过 `publish`（人工确认）和没接线的 `mux`（没法混）。

### 3.4 缓存

节点键 = SHA-256(`type`, `params`, 所有祖先产出 `[kind, sha256]`, `v=studio-graph-3.9.0`)。改参数只 `invalidate_downstream()`；上游/平行分支不动。命中要所有产出文件都在，避免半截缓存冒充命中。

### 3.5 复用而不是复制

- 生图：`_gen_images/_image_one`，节点 id 当产出文件名；`shot:sN` 参考图会映射到同工程的其他生图节点。
- 配音：`_gen_tts` 的本地/百炼分支 + `_build_voice`，按节点前缀生成音频/字幕/时间轴；多行台词逐句生成。
- 配乐：`_gen_bgm` 加产出名参数。
- 网页/PPT：`render_web.render_all` / `render_ppt.render_all`；看图复刻单独用 `render_html_file`。
- 混流：把上游投影成 `shots/files/settings`，`_build_voice` 拼全局配音，`compose_video(project=...)` 复用 FFmpeg 逻辑。
- 发布：`publish.check_item/ask` + `to_publish`。

### 3.6 旧工程迁移

`Studio._load()` 是唯一入口：

1. 没有合法 `graph` 时，先把 `project.json` 复制成 `project.json.bak`（已存在不覆盖）。
2. `migrate_from_shots()`：一图一 `image` 节点、一句一 `voice` 节点；`render=web/ppt` 再拆 `web/ppt` 节点；配乐/混流/发布各 1 个；产出、`img_fps`、`tts_fp` 原样保留。
3. 连线：所有图/音/网页/PPT → `mux`，`mux` → `publish`。
4. 失败：把 `.bak` 复制回 `project.json`，抛 `StudioError`，原工程不动。
5. 已有合法 `graph` 不再迁移。

### 3.7 灯箱安全

`app/studio_assets.py`：

- 根只认项目目录或 `_cache`；
- 拒绝绝对路径、盘符、`..`、NUL、解析后越界（符号链接指到外面也会被 `resolve()` 后拦下）；
- 只给 PNG/JPEG/WEBP/GIF/SVG，且文件头必须和后缀一致；
- SVG 响应带 `Content-Security-Policy: sandbox; default-src 'none'; ...`，前端只用 `<img>`；
- 只读，不写不删。

### 3.8 剧本驱动

`docs/视频工坊剧本格式.md` 是事实标准。`_apply_script_doc()`：

- `script_key = "image:<id>" / "voice:<id>" / "web:<id>" / "ppt:<id>" / "bgm:<id>"`；
- 同 key 更新参数、保留 outputs 和 cache_key；
- 自动接 `mux` 和 `publish`；
- 剧本里没有的节点标 `script_removed` 并断开到混流的线，不删除；
- 导入不调用任何生成函数，只返回预估费用。

### 3.9 看图复刻

- 只在网页动效节点按钮点击时调用：前端 `confirm()` 明确写「会消耗 Claude Code 额度」。
- `ccode.run()`：`claude -p`，cwd=工作区，提示词从 stdin，`CREATE_NO_WINDOW`。
- 提示词：参考图路径、W×H、FPS、时长、60-30-10、禁止外链、不放 logo/商标。
- 产物 `styleframe/<节点>/index.html` → `render_web.render_html_file()` 录成 `render/web_<节点>.mp4`，进 `_cache/tracks/`。
- 节点缓存键含上游参考图哈希 + FPS/时长；`styleframe_on` 区分「普通网页动效」和「复刻」，同参数再点直接命中，不再调用 Claude Code。
- 失败不重试；停下按进程号结束。
