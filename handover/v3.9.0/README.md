## 关键结论

1. **旧工程能自动迁移**：第一次打开旧项目，每张分镜图拆成独立生图节点、每句配音拆成独立配音节点，产出和缓存指纹保留；迁移前留 `project.json.bak`，失败原工程不动。
2. **不偷偷花钱**：单节点运行缺上游直接报「缺上游产出」；剧本导入只建节点和连线，返回预估费用；看图复刻只在点按钮时调用 Claude Code，并显示额度提示。
3. **灯箱是通用组件**：所有节点产出、PPT 幻灯片、封面都走同一个 `Lightbox`；后端只读取图接口限制在项目目录和 `_cache`，越界/符号链接/假图片都有测试。
4. **旧页面没动**：生图、配音、配乐、批量、发布、对话、监控等独立页面保持原样，工坊只调用它们的底层函数。
