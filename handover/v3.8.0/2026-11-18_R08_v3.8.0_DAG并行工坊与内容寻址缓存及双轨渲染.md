## 这一轮做了什么

把视频工坊从 6 张固定卡片重构为专业生产工作台。原有 `img`、`tts`、`bgm`、`publish`、`monitor` 等页面保持不变。

### 1. 画布与动态子工作流

- 8 个顶层节点：① 剧本与策划、② 分镜生图组、③ 角色配音组、④ 背景配乐、⑤ 网页动效、⑥ PPT/OnlyOffice 卡片、⑦ FFmpeg 终混、⑧ 发布与排期。
- 每个分镜自动派生独立生图子节点；每句台词自动派生独立配音子节点；挂在可折叠、可缩放的组容器里，子节点可单独改参数、重跑、试听、选图。
- 所有顶层节点/组容器右下角有缩放手柄；`ResizeObserver` 实时重算 SVG 贝塞尔连线；节点 `(x,y,w,h,collapsed)` 防抖写入 `project.json` 的 `node_layout`，刷新/重开恢复；「居中复位」回默认布局。
- 画布空白拖动平移、滚轮缩放、节点标题拖动；外层窗口不滚，画布/组内滚。

### 2. 内容寻址缓存（新 `app/studio_cache.py`）

- 全局 `工作区/视频工坊/_cache/` + 项目 `cache_index.json`。
- 生图指纹：`model + prompt + aspect_ratio + resolution + quality + complexity + custom_w/custom_h + transparent + gif_frames + gif_delay_ms + ref_image_sha256 + variant`。
- 配音指纹：`engine + speaker + tone + text`；配乐：`prompt_en + duration + steps + seed`。
- 命中直接把缓存文件复制到项目产出，节点标 `缓存命中`，不调用付费 API；指纹变了才 `stale` 重做。

### 3. 三路异构并行 DAG

- `asyncio.Semaphore(4)` API 通道：生图 + 百炼云端配音并发。
- `GPU_LOCK` 本地通道：本地 Qwen3-TTS 与 Stable Audio 3 串行；换模型前停上一个服务。
- 生图、配音、配乐同时 `gather`；全部 ready 后汇聚到视觉渲染 + FFmpeg。
- 分支失败只阻塞下游：生图全失败才阻塞，部分失败用已有图；配音任一句失败阻塞成片；配乐失败降级无配乐；已完成缓存保留。

### 4. 全参数生图

- 模型下拉含 `gpt-image-2.6-sunburst` / VIP（GIF）、GPT Image 2.5、Nano Banana、Seedream、Flux 等；`imagegen.catalog()` 动态读取。
- 比例 9:16/16:9/1:1/3:4/4:3/2:3/3:2 + `custom_w/custom_h`。
- 分辨率 1K/2K/4K；`n=1~4`（缩略图选中最终图）；画质、构图复杂度、透明。
- 参考图：上传到项目 `refs/`，或 `shot:s1` 引用同工程其他分镜图。
- GIF：帧数默认 8、每帧毫秒默认 150；新增 GIF 文件头识别；生成后节点内循环预览，选中的 GIF 可作为动态画面轨。
- `imagegen.call_images()`：OpenAI 兼容线路一次请求 n 张，其它线路循环 n 次。

### 5. 网页动效 + PPT 双轨渲染

- **`app/render_web.py`**：Playwright 无头 Chromium + 虚拟时间逐帧截图，pipe ffmpeg 生成 H.264 轨；深色毛玻璃、网格/粒子/光影、动态高亮字幕、Q 版 GIF 白边圆角贴纸位移；可调背景、字幕位置/字号/颜色、GIF 缩放、动效强度、fps。
- **`app/render_ppt.py`**：`python-pptx` 自动生成 `output/卡片.pptx`（9:16/16:9）并渲染每页 PNG；支持导入 `.pptx`，有 LibreOffice/soffice 时转图，没有时降级自动卡片。
- 每镜可选 `render=web/ppt/static`；FFmpeg 取画面顺序：网页轨 → PPT 图 → 生图/GIF → 静态兜底。
- 新增 `playwright`、`python-pptx` 到 `requirements.txt`。

### 6. 发布与排期

- 节点 ⑧ 直接编辑：标题、简介、话题（默认 `ai漫剧 ai创作浪潮计划 搞笑`）、封面（自动/指定分镜）、定时（2 小时~14 天）、自主声明（AI 生成内容合规声明）。
- 单条送审写 `pub_pending`；批量加入 `pub_batch`（同视频去重更新），批量必须定时。
- **仍严格保留「发布」窗口人工二次确认锁，绝不自动点击最终发送。**

### 7. 本机测试安全锁

`dev/serve.sh start` 检测到真实 `data/secrets.bin` 默认拒绝启动（退出码 3）；显式 `AGENT_ALLOW_OVERWRITE_DATA=1` 才允许，且先备份 `data/secrets.bin` / `settings.json`，`stop` 自动还原。本轮全程没有覆盖真实 data。
