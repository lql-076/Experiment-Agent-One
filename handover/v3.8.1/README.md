## 这一版做了什么

1. **空项目开箱可测：** 新建/打开空项目默认在节点 2 放 1 个分镜节点、节点 3 放 1 个配音节点；**连项目都没有时进入视频工坊会自动建草稿项目**，不拆剧本也能单独测生图/GIF/百炼配音/配乐。
2. **手动增删：** 两个子工作流组都能 `+ 添加分镜/台词节点`，每个子节点有「删除」；删空后还能再加。
3. **GPT Image 2.6 全参数：** 普通/GIF/SVG 三态；PNG/JPEG/WebP + 透明；GIF 帧数 2~16、每帧 20~2000ms、实时总时长；SVG 矢量图；最多 16 张 JPG/PNG 参考图（单图 ≤20MB）或 `shot:sN`；quality 6 档、complexity 3 档、n=1~4。
4. **自定义尺寸刚性校验：** 16 倍数、长边 ≤3840、比例 ≤3:1、像素 655,360–8,294,400；前端提示并禁用，后端双重拦截。
5. **双轨缓存：** 网页动效与 PPT 卡片按输入图/时间轴/配置或 `.pptx` 内容哈希缓存到 `_cache/tracks/`；第二次直接复用，不再启动 Playwright；只改配乐/混音时只重跑 FFmpeg。
6. **后端透传：** `output_format`、`background=transparent`、`quality`、`complexity`、`size`、`n`、多参考图 `images/edits`；GIF/SVG 头识别，SVG 终混前自动转 PNG。
