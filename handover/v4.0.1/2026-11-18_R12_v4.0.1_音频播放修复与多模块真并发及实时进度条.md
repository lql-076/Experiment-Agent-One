1. **配音/配乐点「听」报 `Failed to load because no supported source was found`**：媒体白名单和 Range 缺失。
2. **不能同时点多个模块运行**：`Studio` 只有一个全局任务和 409 锁。
3. **点了运行后没有任何实时进度**：模块没有 runtime 状态，前端也没显示。
4. **生图测试台秒回旧图**：命中模块/全局缓存，且图藏在参数底部。
5. **配乐听起来像没声/很闷**：模型原始输出峰值只有 -11 dB，没有归一。
6. **配乐页偶发黑屏/灰按钮**：后台没响应时页面不渲染错误状态。

## 3. 设计细节

### 3.1 媒体播放

- WAV：`RIFF....WAVE`；MP3：`ID3` 或帧同步；FLAC：`fLaC`；OGG：`OggS`；MP4：`ftyp`；WebM：EBML。
- 后缀和文件头对不上就 404；`..`、绝对路径、符号链接越界继续拒绝。
- `FileResponse` 支持 Range；前端 `<audio>` / `<video>` 使用输出 SHA-256 的 `&v=`，重配后不会读旧缓存。
- 模块内原生控制条：播放/暂停、当前/总时长、可拖动进度条；失败时显示 `detail`。

### 3.2 模块级并发

```python
self._tasks: dict[str, asyncio.Task]
self._stops: dict[str, threading.Event]
self._jobs: dict[str, dict]
```

- 不同模块各一个 task；同一个模块重复点才返回 409。
- `stop(module_id)` 只设该模块的 Event；不传则设全局 `_stop` 和全部模块。
- `contextvars` 记录当前模块，`_stopped()` 同时看全局和本模块，子线程/嵌套协程不会串。
- API 继续 `Semaphore(4)`；本地 GPU 用 `_gpu_lock` + `_gpu_busy`，第二个本地模块 `status=queued`，文案「正在等待上一本地模型释放 GPU…」。
- `_save` 只替换当前模块到磁盘最新工程，并保留最新布局 x/y/w/h，避免并发保存把拖动位置写回旧值。
- `_rebuild_voice` 在锁内重新读最新工程，合并白页/紫苏最新的逐句产出，避免两个配音并发时只保留一个角色。

### 3.3 生图真出图与配乐响度

- 生图模块运行带 `force`: 后端写入一次性 `_force_nonce`，模块缓存键和生图全局指纹都变，真的调 API易；产出大图放在模块顶部。
- `bgm_server.generate()` 写文件前按峰值归一到 -1 dBFS；配乐指纹加 `v=2`，旧偏小文件不再命中。
- 配乐页 `bgmEnter()` 先渲染「正在连接后台」，fetch 失败显示原因并禁用生成按钮，1.5s 轮询恢复。

### 3.4 实时进度

模块 `runtime`：

```json
{"status":"running","pct":42.5,"phase":"正在合成第 2/5 句（白页，语气：冷静吐槽）…",
 "started_at":1795012345.6,"last_took_s":0}
```

- 状态：`idle / queued / running / ok / error`。
- 阶段：
  - 模块 1：DeepSeek 拆解 → 解析并写 5 份清单。
  - 模块 2：请求 API易 → 下载校验 (1/N)。
  - 模块 3/4：逐句合成 → 拼接/SRT/时间轴。
  - 模块 5：启动/检查 Stable Audio 3 → 生成 → 写 bgm.wav。
  - 模块 6：网页帧号/总帧、PPT 页数、FFmpeg 百分比/帧率/帧号。
- 前端：运行按钮立即变「运行中 · X%（点此停止）」；卡片 `.st-live` 呼吸边框；`.st-rt` 进度条 + 阶段大字 + `已耗时 12.4s`；完成后 `耗时 18.2s`。
- 轮询：有 running/queued 时 600ms，否则 1300ms；只更新 runtime DOM，不重绘表单焦点。
