## 二、核心架构决策

1. **Breeze 判定统一**：安装器 `breeze_done()` 与运行时 `voice.model_ok()` 必须使用同一套规则；`.cache` 是 HF 下载缓存，不应算作“模型没下全”。
2. **窗口崩溃必须先有日志**：pythonw 下 stderr 为 `None`，pywebview 的 `StreamHandler` 也写向 `None`；因此窗口进程自己建立 `window.log`，并在导入 pywebview 之前配置 logger。
3. **不让异常穿过 pythonnet**：CLR `0xe0434352` 的根因是 Python / .NET 边界上的异常转换失败；所有 `window.pywebview.api.*` 方法统一捕获并返回安全值。
4. **NVML 移出后端主进程**：NVIDIA 驱动的访问违例不是 Python 异常，`try/except` 抓不住；放进独立的硬件监控助手进程，最坏只重启助手。
5. **崩溃记录可轮转**：`crash.log` 与 `backend.log` 一样按大小轮转，避免一次访问违例写成几十 MB。
