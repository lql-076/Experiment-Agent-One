# 做视频
用在：用网页动画 + 配音 + 配乐做一条视频（片头、讲解、口播都行）
触发：做.{0,12}(视频|片头|片尾|短片|动画)|渲染.{0,4}视频|录成视频|口播

照这个顺序做，每一步做完更新计划（update_plan）和这件事文件夹里的 进度.md。一条视频放一个文件夹，比如 `视频\第3期\`。

## 1. 先定稿
- 没给文案：先写文案（口语、短句，一句一个意思），存成 `文案.md`。他给了就用他的，不改他的话。
- 定画面大小：横屏 1920x1080（B 站），竖屏 1080x1920（抖音）。没说就横屏。

## 2. 配音（先有声音，画面跟着声音的时间走）
- `make_voice`：text 只放要念的字，dir 写这件事文件夹里的 `配音`。回来三个文件：`.wav`、`_时间轴.json`、`_字幕.srt`。
- 读 `_时间轴.json`：`segments` 里每句有 `start`、`end`（秒）和 `text`。**画面的每一段什么时候出现，按这个时间写，不要自己估。**
- 没有配音工具时：告诉他去配音页生成，把文件拖进对话；或者先做没有声音的版本。

## 3. 画面：写一个网页
- 一个 `index.html`，body 固定成画面大小、不要滚动条，深色或他指定的风格。字体用 `"Microsoft YaHei"`。
- **写一个 `window.seek(t)` 函数**（t 是秒）：把整个画面摆成第 t 秒的样子。所有动画都从 t 算出来（位置、透明度、哪句字幕亮着），不要用 setTimeout 攒状态。这样录出来一帧不差，也能随便跳到哪一秒检查。
  ```js
  const SEG = [/* 从时间轴.json 抄过来：{start, end, text} */];
  const ease = x => x < 0 ? 0 : x > 1 ? 1 : 1 - Math.pow(1 - x, 3);
  window.seek = t => {
    const i = SEG.findIndex(s => t >= s.start && t < s.end);
    caption.textContent = i < 0 ? '' : SEG[i].text;
    title.style.opacity = ease(t / 0.6);
    title.style.transform = `translateY(${(1 - ease(t / 0.6)) * 40}px)`;
  };
  ```
- 长文件分段写（write_file 每段 3000 字以内，后面的 append=true）。
- 图片素材用相对路径（放在同一个文件夹里）。图里不放文字，字用网页排。
- 要角色跟着说话：用 `工具箱\口型.py`（差分图：闭嘴、张嘴，可选半张、闭眼）。

## 4. 先截图检查，再录
- 截几张：`python 工具箱\录网页.py 视频\第3期\index.html 视频\第3期\检查1.png --png 2.5`，然后 `look` 看：字有没有出框、有没有重叠、是不是黑屏、中文是不是方块。
- 有问题改网页再截，没问题再录整段。**没看过画面不要说做好了。**

## 5. 录成视频
- `python 工具箱\录网页.py 视频\第3期\index.html 视频\第3期\画面.mp4 --seconds 时长 --fps 30`
- 时长 = 配音时长 + 头尾各留半秒到一秒。
- 一条命令最多跑十几分钟：超过 90 秒的视频分段录（`--start 0 --seconds 60`、`--start 60 --seconds 60`……），最后用 `合成.py --video 段1.mp4 段2.mp4` 接起来。
- 第一次用先装：`pip install playwright imageio-ffmpeg`（浏览器用电脑上的 Edge，不要 playwright install）。

## 6. 合成
- `python 工具箱\合成.py --video 画面.mp4 --voice 配音\旁白.wav --bgm 配乐.wav --out 成品.mp4`
- 配乐：有 `make_music` 就出一段（比视频长一点，纯音乐）；没有就用他给的；都没有就不加。
- 字幕已经在画面里排了就不用 `--srt`；想烧进去再加 `--srt 配音\旁白_字幕.srt`。

## 7. 交付前自己看一遍
- `look` 成品（开头、中间、结尾三处）；`media_info` 看时长对不对。
- 回复里说：成品在哪（相对路径）、多长、哪些地方是凑合的、下一步建议。不要长篇大论。

## 容易踩的坑
- 命令里的路径有空格要加引号；Windows 的 cmd 里用反斜杠。
- 不要在命令和脚本里写工作文件夹外面的绝对路径（会被拦）。
- 出错先看报错最后几行；同一个办法失败两次就换办法。
- 做到一半步数快用完：先把 进度.md 写清楚（做完了什么、文件在哪、下一步），他说「继续」时先读它。
