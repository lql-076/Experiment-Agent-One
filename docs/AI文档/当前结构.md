## 接口（都在 127.0.0.1:8765）

## 数据和日志都在哪

| 位置 | 是什么 |
| --- | --- |
| data/settings.json | 设置 |

| data/logs/backend.log | 后端的输出（平时没有黑窗口，出了问题先看这里） |
| data/logs/model_server.log、kev.log、tts.log、hw_helper.log | 本地模型服务、Kev、配音服务、硬件监控助手 |
| data/tts/ | 最近一次生成的配音（试听用，只留一份）；try/ 是云端音色的试听（念过的不再花钱） |
| data/logs/setup_*.log | 一键补齐每一步的原始日志 |
| data/logs/report.jsonl | 进展报告 |
| data/logs/actions.jsonl | 动作日志（哈希链，改不了） |
| memory/ | 记忆、技能、提示词、Claude 总结（中文 Markdown，git 记录改动） |
| training/ | 慢成长的样本 |
| models/ | 底座、嵌入模型、小脑、Kev 权重、配音模型（models/tts） |
| ai-env/、tts-env/、.venv/ | 三个 Python 环境（本地模型、配音、后端） |
| 配音输出/ | 保存的配音：一次一个文件夹（WAV、时间轴、字幕、文案） |
| tools/ | 便携版 Git、PyTorch 安装包、下载缓存、临时文件 |
