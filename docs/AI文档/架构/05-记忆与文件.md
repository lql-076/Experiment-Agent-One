## 做什么

agent 自己有一个文件夹，放记忆、技能、提示词、从更强的模型带回的总结，全是中文 Markdown，你随时能打开看、改。快成长就是改这个文件夹。

## 文件夹里有什么

默认是 `memory\`，可以在 设置 › 记忆与文件 改到 Obsidian 库里的一个子文件夹。

```
memory\
  记忆\收件箱.md      你说"记住……"的内容先进这里
  记忆\关于我.md      每日差事整理后的长期记忆
  技能\               做事的方法，每个技能一个 .md（什么时候用、怎么做、注意什么）
  提示词\人设.md      它的说话方式（改提示词：先斩后奏，事后写进报告）
  总结\               从更强的模型（网页 Claude、ChatGPT……）带回的总结和聊天记录（只当参考资料读）
```

## 怎么走

- **写：** `memory.write` 有几道关，写入后再提交 git：
  - 只能写这个文件夹，越界直接报错；
  - 要过安全闸，默认先斩后奏；
  - 写入后 `git commit` 一次；
  - 在报告的「先斩后奏的改动」里记一条，能一键撤销（git revert）。
- **"记住……"：** 程序认出来，追加一行到 `记忆\收件箱.md`（带时间），不经过模型。
- **整理：** 每日差事里，DeepSeek 把收件箱的内容合并进 `关于我.md`，会去重、合并同类、把过时的改掉。
  - 涉及隐私的行留在收件箱，不交给 DeepSeek，等以后本地小脑整理。
  - 整理完清空收件箱里已合并的部分。
- **检索：**
  - 文件切成小段，用嵌入模型算向量，存在数据库 `chunks` 表；只算新增的，删掉的段会清掉。
  - 回答前拿消息的向量找最相关的几段（默认 4 段）一起交给模型。
  - 交给 DeepSeek 时不带隐私段。
  - 记忆只在这个文件夹里找。
- **说明书（给 agent 自己读）：**
  - `docs\操作手册.md` 和 `docs\AI文档\` 下的全部文章也切块、算向量，存在同一张 `chunks` 表，`file` 前面加 `@说明/`，和记忆分开找。
  - 说明书是公开的，里面举例提到"吃药""密码"不算隐私。
  - 只在问到 agent 自己时才查（`memory.about_agent`），取最相关的 3 段。嵌入模型没开时，按字面重合找。
  - 每批算 64 段，一次没算完下次接着算。
- **git：**
  - 用 git 记录每次改动（可关）。
  - 用的是一键补齐装的便携版 Git，配置只写在这个文件夹自己的仓库里，不改你系统的 git 设置。

## 能读的文件夹（v1.8.17，`app/files.py`）

agent 只能**写**自己的文件夹；别的文件夹要你在 设置 › 记忆与文件 ›「能读的文件夹」里加了才能**读**（只读：不改、不删、不运行）。

- **加：** 只能你在界面上点（设置里填路径点「允许读」，或者对话里回复下面的「允许读这个文件夹，再问一次」）。这是给 agent 加权限，记进动作日志（`tool.add`）；模型自己加不了。不能加 Agent 自己的 data 文件夹、不能加整个盘。存在设置的 `readDirs`（通用的「改设置」接口改不了它）。
- **每个文件夹一个开关「能发给 DeepSeek」：** 默认开（作者 11-04：笔记仓库这类发给 DeepSeek 没问题）。关掉的只给本地小脑看：DeepSeek 的工具看不到它，你贴了它里面的路径也只交给本地小脑。
- **能读什么：** .md .txt .docx、代码、表格（.csv）、日志这些文字（UTF-8、GBK 都认，一次 2 万字，长的接着读）；图片（给 DeepSeek 看）。程序、压缩包这些不读。
- **怎么防越界：** 路径先 resolve（快捷方式、符号链接走到真的位置），再看在不在允许的文件夹里，`..` 绕不出去；Agent 的 data（设置、密钥、数据库）和看着像密钥的文件（.env、*.key、id_rsa、.kdbx……）不管在哪都不读；.obsidian、.git、.trash 这些不列、不搜。
- **怎么用：**
  - 消息里贴了路径（`E:\笔记仓库\人物.md`，后面紧跟着中文也认得出）：程序直接读出来，跟消息一起交给模型（本地小脑只放前 3000 字）。贴的不在允许里：不读，回一句「允许读这个文件夹」。
  - 问「我笔记里 XX 是怎么写的」：交给 DeepSeek，它带着三个工具 `list_dir`（列目录）、`find_files`（按文件名和内容搜）、`read_file`（读，图片附在下一条消息里），自己翻。本地小脑不会用工具，这类问题不交给它。
  - 每读一个文件，事件里记一步「读文件」，`chat_files` 表记一笔，对话页回复下面写着读了哪些。

## Agent 自己的工作文件夹（v2.1，`app/workspace.py`）

作者 11-06 / 11-08：单独给 Agent 一个文件夹，在里面写、删都行，但要有备份，备份半年清一次、清的时候出清单；后来又说要让 DeepSeek 通过 API 自己试着做视频，"必要的权限都要给它"。

- **在哪：** 默认 Agent 文件夹里的 `工作区`（设置 › 记忆与文件 能换，`wsDir`；不让放进 Agent 自己的文件夹（app、data、models……）、Agent 文件夹本身或上级、整个盘、系统文件夹）。换位置、开关「能运行程序」（`wsRun`）是给 agent 的权限：只走 `/api/ws`，通用的改设置改不了（`settings.PERM`），记进动作日志。
- **能做什么（给 DeepSeek 的工具）：** `write_file`（新建 / 覆盖 / 接着写，一次 2 MB 文字）、`edit_file`（old 换成 new，只出现一次或 all）、`delete_path`、`move_path`、`copy_path`（src 可以是能读的文件夹里的，把素材拿进来）、`run_command`；读用原来的 `list_dir`、`find_files`、`read_file`（工作区自动算能读的，相对路径按工作区算）。路径先 resolve 再判断在不在工作区里，`..`、绝对路径、符号链接都出不去；`.env` 这类不写。
- **备份：** 改、删、覆盖之前旧的进 `工作区备份\日期\时分秒_动作\原来的相对路径`（删 = 整个挪进去）。备份在工作区外面，它的工具删不到。
- **半年清一次（`workspace.clean`，`workspace.loop` 每 6 小时看一次）：** 第一次只记下从哪天开始算（kv `ws_clean`）；离上次满 182 天就把放了超过 182 天的日期文件夹删掉，清单写进 `工作区备份\清理清单\日期_清理清单.md`（哪天、几点、当时在做什么、原来在哪、多大），`feed.add` + `feed.done`（主页「刚做完」）。
- **运行程序（`workspace.run`）：** cwd 是工作区，`shell=True`（Windows 的 cmd），`CREATE_NO_WINDOW`，放进 Agent 的作业对象（Agent 关了它也停）；PATH 最前面是 `ws-env`（第一次运行时用 Agent 的 Python 自动 `-m venv` 建）；TEMP / TMP 指到 `工作区\.临时`，`PLAYWRIGHT_BROWSERS_PATH` 在 ws-env 里，pip 默认清华镜像。超时（默认 300 秒，最多 `wsTimeout` 900 秒）按 PID 连子进程一起停。输出给模型最后 6000 字，完整的写 `data\logs\workspace.log`；改了哪些文件对比前后列出来。pip 装了 imageio-ffmpeg 后把它带的 ffmpeg 复制成 `ws-env\Scripts\ffmpeg.exe`。
- **拦哪些（`workspace.guard`）：** 每段命令的第一个词是 del / rd / rm、format、reg、shutdown、taskkill、net、sc、schtasks、icacls、PowerShell、start、cmd 这类的；命令里有工作区和 ws-env 外面的绝对路径、`..`、`%USERPROFILE%` / `$env:` / `~\`；工作区里的脚本（.py .js .bat …，300 KB 以内）写死了外面的绝对路径或者用了 expanduser、USERPROFILE、APPDATA 这类。**不是真沙箱**：拦的是手滑和明显越界的，脚本还是能碰到别处（作者知道）。
- **对话里：** `workspace.wants` 认出「做视频、写脚本、记到 XX 文件夹里、运行……」时不交给本地小脑（它不会用工具），交给 DeepSeek；「帮我记一下，记到 XX 文件夹里」不走「记住」的快捷处理（`workspace.to_file`）。带着工作区工具时一件事最多 `wsRounds`（40）步、一次最多出 8000 token；每一步进事件（写文件、改文件、删除、挪、复制、运行 · 几秒 · 成功 / 退出码 / 超时）。动了工作区的不存训练样本。

- **v2.2 · DeepSeek 把工具调用写成了文字（11-08 做视频连续三次失败）：** 没给它工具、或者回复被截断时，它会把调用按内部格式（`<｜DSML｜function_calls>…`）写进正文。`deepseek.parse_dsml` 认得出、写完整了就照常执行（步骤「认出写成文字的工具调用」）；被截断的（`finish_reason=length`，或者没写完）不执行，加一句「程序提示」让它用工具调用、分段写再来（一件事最多提醒 2 次，步骤「工具调用没成」）；这串文字一律 `strip_dsml` 去掉，不显示、不进历史（不然下一句它照着写）。
- **v2.2 · 400 不再悄悄去掉工具：** `deepseek.chat` 被拒（400）时依次：改成不思考 → 在工作区干活时去掉消息里的图片（带图片 + 工具最容易被拒，之后整件事都不带图）→ 最后才不带工具。每次被拒的原因写进 `data\logs\deepseek.log`（不写 Key 和消息内容），事件里有「DeepSeek 拒了一次」。
- **v2.2 · 步数和接着做：** 第 N 步进「现在」（DeepSeek 正在接着做（第 N 步，最多 40 步））；剩 3 步时提醒它把做到哪写进 `进度.md`；最后一轮不给工具，让它汇报做到哪。说明里要求长文件分段写（每段 3000 字以内，`append=true`）、步骤多的活记 `进度.md`。说「继续 / 接着做 / 开始第 2 步」（`agent.CONT_RE`，40 字以内，上一件动了工作区的事在 2 小时内）：不交给本地小脑，交给 DeepSeek 带着同样的工具，并把上次在工作区的最后 15 步和最后一句话带上（`LAST_WS`，只在内存里）。
- **v2.2 · 对话里发来任何文件：** 拖进来、Ctrl+V、回形针，什么文件都收，马上流式传到 `/api/ws/upload`（请求体就是文件本身，一个最多 2 GB，先写 `.part` 传完再改名），存进 `工作区\收到的\日期\原文件名`（`workspace.safe_name` 去掉 Windows 不认的字符、不带路径；重名加 (2)）。发消息时带上 `files`（只认 `收到的` 里真有的），这条交给 DeepSeek，消息里写清楚文件在工作区哪，200 KB 以内的文字文件把内容（前 1.2 万字）也带上。图片照旧另外交给 DeepSeek 看。隐私的那句照旧只在本地。

## 对话里的图片（v1.8.17）

界面上点回形针、Ctrl+V 粘贴、拖进对话页都行，一次最多 6 张、一张 10MB 以内，认文件头（PNG / JPEG / WEBP / GIF）。存一份在 `data\chat\日期\`（聊天记录里显示缩略图、换它重做时再用），`chat_files` 表记着是哪条事件的。

## 设置

设置 › 记忆与文件，具体有这几项：
- agent 自己的文件夹
- 用 git 记录每次改动
- 日志保留天数
- 能读的文件夹（只读）：路径、能不能发给 DeepSeek、不让读了
- Agent 的工作文件夹（v2.1）：在哪、多少文件、备份多大、上次 / 下次清理、「能运行程序」、换位置、打开、看清理清单

## 文件

- `app/memory.py`：读写、git 提交、撤销、切块和检索。
- `app/files.py`：能读的文件夹、列目录 / 搜 / 读、消息里贴的路径、对话里的图片（v1.8.17）。
- `app/workspace.py`：Agent 自己的工作文件夹（v2.1）。
- 数据库：`chunks`（记忆向量）、`changes`（改动记录，撤销用）、`chat_files`（每条事件带的图片、读过的文件）。

## 限制和还没做的

- 技能现在要手写，agent 还不会自动生成和打磨技能，这是借鉴 Hermes Agent 的那一部分。
- 隐私记忆的整理要等本地小脑训练好。
- 能读的文件夹现在是现翻（按关键词搜），还没像记忆那样建索引（切段算向量）；笔记很多时搜得慢一点。
