# 架构 · 成长与训练

> 最后核对：v1.4.0。

## 两种成长

| | 快成长 | 慢成长 |
| --- | --- | --- |
| 改什么 | 文件夹：记忆、技能、提示词 | 模型本身：新的小脑（LoRA）、决策脑的判例 |
| 多久生效 | 当场 | 攒够样本 → 你同意 → 训练 → 考试及格才上线 |
| 你怎么看懂 | 直接读，全是中文 Markdown | 看报告里的准确率和本地处理比例 |
| 素材从哪来 | 每次对话、你让它记住的、Claude 带回的总结（只读） | DeepSeek 的处理记录 + 你的纠正 + 本地模型自己的输出 |

## 慢成长怎么走

```
决策脑对所有本地小脑都没把握 → 记为「新类别」，先交 DeepSeek
  → DeepSeek 的回答存成样本（training\samples.jsonl）
  → 每日差事：嵌入模型把新类别的消息按相似度分组，DeepSeek 给每组起 2~4 个字的名字（categories 表）
  → 每日差事：出题造样本——仿照真实例子写变体，真实样本至少占 25%（training\synthetic\<类别>.jsonl）
  → 某一类样本数 ≥「新建一个小脑需要的样本数」（默认 200）→ 状态改成「攒够了」
  → 在 QQ 和界面上问你「要不要训练」（app/growth.py）
       回「开始 / 允许 / 可以」→ 记为同意（状态 approved）
       回「等一下 / 等我忙完 / 晚点」→ 过「没回的话，隔多久再问」（默认 2 小时）再问
       不回 → 隔同样时间再问，直到你回；开着免打扰时不问
  → 训练新小脑（还没接）→ DeepSeek 当考官，用没参与训练的记录考试，≥ 及格线（默认 85 分）才上线（还没接）
```

不按钟点训练：你的作息不固定，夜里电脑也常关着，所以是"攒够了就问你"，你说开始才开始。训练时显存不设上限。

## 哪些能进训练数据（固定，改不了）

| 能进 | 不能进 |
| --- | --- |
| 你自己的消息、你的纠正 | **任何 Claude 的输出**：网页 Claude 的回答、带回的总结、和 Claude 的聊天记录 |
| DeepSeek 的处理记录（DeepSeek 官方允许用它的输出训练别的模型） | DeepSeek 回答时参考过 Claude 内容的那些记录 |
| 本地模型自己的输出 | 隐私内容 |

规矩写在 `training\README.md`，代码里在存样本时拦住（`app/agent.py` `_save_sample`）。

## 设置

设置 › 成长与训练，具体有这几项：
- 快成长：允许自动写技能和记忆
- 每日差事
- 出题造样本
- 真实样本至少占
- 新建一个小脑需要的样本数
- 慢成长：攒够样本后问我要不要训练
- 没回的话，隔多久再问
- 新小脑上线的及格线

## 文件

- `app/growth.py`：问你要不要训练，记下回答（状态存在 kv `train_ask`）。
- `app/nightly.py`：分组起名、造样本。
- `app/agent.py`：存样本。
- `training\samples.jsonl`、`training\synthetic\`。
- 数据库 `categories` 表：类别、样本数、状态（collecting / ready / approved）。
