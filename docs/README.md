# 说明文档 · 目录

这个文件夹分两部分：**给人看的**和**给 AI 看的**，全是中文 Markdown。

- **给人看：** 打开界面侧栏「说明」。
  - 每个功能一张树状图，节点能点开、收起；QQ、模型服务这些节点按实时状态亮灯。
  - 操作手册、更新记录照常是文字。
- **给 AI 看：** `AI文档\` 文件夹，是同一批架构说明的文字版。读者是 DeepSeek、本地的大脑小脑，以及接手开发的 Claude。

图和文字写在同一个文件里：每篇架构说明开头那段 mermaid 就是图，后面是文字。改一处，图和文字一起更新，不会对不上。

## 怎么保持最新

- **「当前结构」不会过时。** 后端每次启动都按代码重写一遍。新加了接口却没写说明，那一行会标「还没写说明」。
- **架构说明跟着版本改。** 每出一个新版本，改到哪一块，就同步改那一块的结构图和文字，并在「更新记录」里写一条。每篇开头写着它最后核对到哪一版。
- **最终版架构**是作者另外写的目标蓝图（不在仓库里）。「架构 · 总览」最后有一张表，逐条对照「最终版要什么」和「现在做到哪」。
- **代码和文档都在 GitHub 仓库里**，从 v1.4.1 起每一版一个提交，提交说明以版本号开头，哪一版改了哪几行都查得到。怎么接着开发、怎么跑测试，见仓库里的 `dev/README.md`。
