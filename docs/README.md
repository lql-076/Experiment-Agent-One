这个文件夹是 Agent 的说明书和架构图纸，全是中文 Markdown。界面侧栏「说明」读的就是这里，用记事本、Obsidian 直接打开也行。

## 怎么保持最新

- **「自动生成 › 当前结构」不会过时。** 后端每次启动都按代码重写一遍：有哪些文件、多少行、每个文件开头写的用途、所有接口、所有设置项和默认值、主题和它们的手感。新加了接口却没写说明，那一行会标「还没写说明」。
- **手写的文档跟着版本改。** 每出一个新版本，改到哪一块就同步改那一块的架构文档，并在「更新记录」里写一条。每篇文档开头写着它最后核对到哪一版。
- **最终版架构**是作者另外写的目标蓝图（不在仓库里）。「架构 · 总览」最后有一张表，逐条对照「最终版要什么」和「现在做到哪」。
- **代码和文档都在 GitHub 仓库里**，每一版一个标签（v1.4.1 起），哪一版改了哪几行都查得到。怎么接着开发、怎么跑测试，见仓库里的 `dev/README.md`。
