# 操作手册

> 最后核对：v1.7.0（2026-10-23）。界面里每个设置下面都有一行小字说明，这里讲的是"整体怎么用"。

## 一、第一次装

1. **装 Python 3.12。** 安装第一页勾选 *Add python.exe to PATH*。显卡驱动装好就行，Git 不用自己装。
2. **把 Agent 文件夹放好。** 哪个盘都行，路径里最好别带空格，例如 `D:\Agent`。
3. **双击 `启动.bat`。** 第一次会建环境、装依赖，大约 1 分钟，装完自动打开界面。这个黑窗口就是后端，别关。
4. **填 DeepSeek Key。** 设置 › 云端，填好点「保存」。保存后会自动查这个 Key 能用哪些模型，「模型」一栏变成下拉框，选一个就行。
5. **点「一键补齐」。** 设置 › 整备 最上面。它按顺序装好 6 样东西，一共下载约 11GB：
   1. 便携版 Git
   2. 本地模型环境
   3. 底座和嵌入模型
   4. 启动模型服务
   5. Kev 权重
   6. 硬件监控（会弹一次管理员确认，点「是」）
   - 可以关掉界面，它在后台接着装。
   - 侧栏「后台 › 进展报告」能看到每一步在干什么。
6. **接 QQ。** 设置 › QQ 通道，填 AppID 和 AppSecret。用你的 QQ 给机器人发一句话，到 整备 › 绑定你的 QQ 点「是我」，再点「发测试提醒」。
7. **装好以后：**
   - 设置 › 提醒：自带一条示例提醒（默认关着），改成你要的时间和内容再打开。
   - 大脑 › 决策脑：运行中文实测，按两票的准确率自动分配权重。
   - 可选：双击 `开机自启.bat`，以后登录 Windows 自动启动 Agent 和硬件监控助手。

从别的 agent 换过来的话，等这边的提醒测试通过了再关旧的。

## 二、每天怎么用

| 想做什么 | 怎么做 |
| --- | --- |
| 打开 | 双击 `启动.bat`。一打开就是「对话」页。已经在运行的话，它会直接把界面拿出来，多出来的黑窗口自己关掉 |
| 看它现在哪些能用、哪些缺着 | 「对话」页右边的「Agent 状态」，或者「总览」上那张卡片。缺了的点按钮直接去补 |
| 收起到任务栏 | 侧栏「收起」 |
| 关掉窗口，但提醒和 QQ 照常 | 侧栏「关闭」→「关掉窗口」。再打开：双击 `启动.bat` |
| 完全退出 | 侧栏「关闭」→「退出 Agent」。模型服务、Kev 一起停，黑窗口也会关。硬件监控助手是单独的管理员窗口，要自己关 |
| 不想每次都问 | 关闭菜单里勾「记住」，或者 设置 › 外观 ›「点侧栏『关闭』时」 |
| 全屏 / 窗口 | 侧栏「全屏」。窗口模式下拖顶栏移动；拖到屏幕顶部最大化，拖到两边半屏；四边四角能改大小；双击顶栏最大化 |
| 横屏 / 竖屏 | 默认按窗口比例自动切换；侧栏「自动」可以固定横屏或竖屏 |
| 常驻屏（大时钟 + 硬件） | 侧栏「常驻」，或者 5 分钟不动自动进入（设置 › 自动化）。按 Esc 或点一下回来 |
| 换风格 | 侧栏「风格」，或者 设置 › 外观。三套风格的手感不一样，见下面第五节 |
| 玩游戏时看帧数和温度 | 设置 › 游戏内显示 打开，选好显示哪几项、放哪个角。游戏里按 Ctrl + Alt + F10 藏起来 / 显示。游戏要用「无边框」或「窗口化」模式 |

## 三、和它说话

在界面「对话」页（侧栏第一个）最下面的输入框里发，Enter 发送、Shift + Enter 换行；也可以在 QQ 里发。两边走的是同一条路，QQ 上的对话也会出现在「对话」页。

每条回复下面有一行小字：交给谁、把握高不高、联网查了几次、花了多少钱。点它，右边会显示这条是怎么处理的：分数、为什么、每一步、查过的网页。判错了也在那里改。

| 你说 | 它怎么做 |
| --- | --- |
| "每天晚上十点提醒我吃药"、"半小时后提醒我收衣服" | 程序直接建提醒，不经过模型 |
| 提醒来了以后回"吃了""好了""收到" | 打卡 |
| 回"晚点""等会""20 分钟后" | 顺延 |
| "记住……" | 写进 `memory\记忆\收件箱.md`，每日差事再整理进长期记忆 |
| 样本攒够、它问你要不要训练时，回"开始"或者"等一下" | 记下同意，或者过一阵再问 |
| "帕鲁最近更新了什么"、"显卡现在多少钱"这类要查最新的 | 交 DeepSeek，它自己上网搜、读几个网页再答，末尾带来源链接 |
| "免打扰在哪设置"、"你能做什么"这类问它自己的 | 先查说明书（这份手册和 `docs\AI文档\`），照着说明书答，告诉你在界面哪里点 |
| 其他任何话 | 决策脑打分：本地小脑处理、交 DeepSeek，或者建议你带着提示词去问网页 Claude |

- **隐私内容只在本地处理。** 比如涉及药、医院、病、密码、银行卡，绝不发给云端，也不会拿去联网搜。本地模型没准备好时，它会先记着，等能处理了再通过 QQ 回你。
- **判错了：** 在「对话」页点那条回复下面的小字（或者在「事件」页点开那件事），选它本来应该交给谁。你的纠正立刻变成新判例，下次就判对。
- **QQ 里的回复是纯文字**（QQ 不显示加粗、列表这些格式）；界面上照常显示格式。

## 四、每个页面

| 页面 | 看什么、做什么 |
| --- | --- |
| 对话 | 和它聊天（一打开就是这页）。右边平时是 Agent 状态，点回复下面的小字切到「这条怎么处理的」。竖屏时右边那块在下面，点「展开」 |
| 总览 | 今天分流了多少、Agent 状态、等你决定的事、下一个提醒、电脑状态、最近事件 |
| 事件 | 每件事的完整记录：收到了什么、四个去向各几分、为什么这么判、每一步怎么走的。可以纠正 |
| 后台 | 正在跑的任务和进度条，各个部分好不好，右边是「进展报告」和原始日志。竖屏时三块一屏放下 |
| 大脑 | 本地小脑、新类别、DeepSeek、网页 Claude 四块，点开看成长记录；网页 Claude 那块能导入带回的总结 |
| 报告 | 这周的分流、本地比例、被你纠正几次、花了多少钱；先斩后奏的改动（能撤销）；等你决定的事 |
| 设置 | 14 个分区，见下表 |
| 说明 | 每个功能一张树状图：点节点收起或展开，带 → 的点了跳到那一篇，QQ、模型服务这些节点按实时状态亮灯；右上角能切到文字版。下面还有操作手册、更新记录 |

设置的 14 个分区：

| 分区 | 管什么 |
| --- | --- |
| 整备 | 14 项"能不能在这台电脑上跑起来"的检查，每次启动自检；点「重新自检」会弹出自检窗口，一项一项转圈变对勾，查完点「去处理」直接跳到要处理的卡片；「一键补齐」 |
| 提醒 | 免打扰开关（开着时只发提醒，别的消息攒着）；所有提醒的增删改、试发 |
| 本地模型 | 模型文件夹、底座精度、闲置卸载、Kev 开关、让路模式、端口 |
| 云端 | DeepSeek Key、余额、模型（下拉框，从官方查）、思考模式、联网搜索（开关、每天最多搜几次、一个问题最多查几轮、「测试一下」）、接口地址、找 Claude 的提示词开头 |
| QQ 通道 | AppID、AppSecret、沙箱、只回复谁 |
| 记忆与文件 | agent 自己的文件夹放哪（可以放进 Obsidian 库）、git、日志保留天数 |
| 分流旋钮 | 本地接手线、新类别线、找 Claude 的线、两票权重、额外隐私关键词 |
| 成长与训练 | 快成长、每日差事、造样本、样本数、训练前先问你、及格线 |
| 安全线 | 哪些事先斩后奏、哪些必须先问你（只能往严里调） |
| 硬件监控 | 数据来源、刷新间隔、整机功耗估算参数 |
| 游戏内显示 | 像游戏加加那样在游戏画面一角显示帧数、温度、占用：开关、什么时候显示、显示哪几项（带预览）、位置、哪块屏幕、字号、透明度、快捷键 |
| 外观 | 风格、亮度、暖色、界面大小、打开方式、关闭按钮怎么做、动效、布局 |
| 自动化 | 多久进入常驻、启动时自检、提醒卡片、没确认时再提醒几次 |
| 数据 | 导出 / 导入设置（不含密钥） |

## 五、三套风格的手感

| 风格 | 手感 |
| --- | --- |
| 星云 | 漂浮：滚轮带惯性；背景和标题有视差；卡片滚进视野时从模糊里浮上来；卡片跟着鼠标微微倾斜 |
| 深海 | 精确：标题吸顶并收窄；顶部滚动进度线和"第几块"；滚动停下对齐到卡片；悬停出现瞄准框 |
| 绛焰 | 杂志：大脑页、主题卡排成横条，滚轮往下 = 往右翻一张，也能按住拖；揭幕式出场；标题后的大字随滚动移动；数字跳动；按钮会被鼠标吸过去 |

嫌晃就到 设置 › 外观 › 动效 选「减弱」或「关闭」。

## 六、更新到新版本

1. 把新压缩包解压到**原来的** Agent 文件夹，选「替换」。压缩包可以是作者发的，也可以从 GitHub 仓库 Code → Download ZIP 下载；后者解压出来的文件夹名不一样，把里面的东西拷进原来的 Agent 文件夹替换就行。
2. 双击 `启动.bat`。依赖有变化会自动补装。

**旧压缩包可以删，Agent 文件夹别删。** 下好的约 11GB、设置和 Key、记忆都在文件夹里，压缩包里没有。删了文件夹就要全部重下、重填。

## 七、出问题怎么办

| 现象 | 先看哪里 |
| --- | --- |
| 界面打不开 | `启动.bat` 的黑窗口有没有报错；或者 设置 › 外观 › 打开方式 改成 Edge |
| 一键补齐某步失败或像卡住了 | 侧栏「后台 › 进展报告」看它最后在干什么；30 秒没动静进度条会标「可能卡住」；原始日志在 `data\logs\setup_*.log` |
| 本地模型服务起不来 | 后台 › 模型服务 那个日志（`data\logs\model_server.log`）最后几行 |
| Kev 起不来 | `data\logs\kev.log`；下不动的话可以先在 设置 › 本地模型 把 Kev 关掉 |
| 整备里缺的项 | 点「一键补齐」；还不行就点那一项的「问 DeepSeek」 |
| QQ 收不到提醒 | 整备 › 测试主动提醒；QQ 里是不是关了"允许主动发送"（关了的话会改成电脑弹窗 + 界面卡片） |
| CPU 温度、游戏帧数不显示 | `硬件监控.bat` 有没有开着；CPU 温度要装一次 PawnIO 驱动；游戏帧数只支持 DirectX 10/11/12 |
| 游戏里看不到帧数小框 | 游戏的显示模式改成「无边框」或「窗口化」（独占全屏会把它盖住）；「只在玩游戏时显示」要硬件监控助手开着才读得到帧数，可以先改成「一直显示」试试；按一下 Ctrl + Alt + F10 看是不是被藏起来了；还不行看 `data\logs\osd.log`，或者看 Agent 状态里「游戏内显示」那一行 |
| 窗口在副屏上显示不全 | 截图到 GitHub 提 Issue；临时可以换成 设置 › 外观 › 打开方式 › Edge |

## 八、文件都在哪

全部在 Agent 文件夹里，不往 C 盘用户目录写：

| 位置 | 是什么 |
| --- | --- |
| `app\` | 后端代码 |
| `ui\` | 界面：`index.html`、`css\`、`js\`（按页面分文件）、`themes\`（一个 .css 一套风格） |
| `scripts\` | 安装、下载用的脚本 |
| `docs\` | 这些说明文档；`docs\AI文档\` 是架构说明的文字版，给 AI 看 |
| `kev\` | 决策脑 Kev 的源码（Apache-2.0） |
| `models\` | 底座、嵌入模型、小脑、Kev 权重 |
| `memory\` | 记忆、技能、提示词、Claude 总结（中文 Markdown，git 记录改动） |
| `training\` | 慢成长的样本 |
| `data\` | 设置、数据库、日志、加密的密钥 |
| `tools\` | 便携版 Git、PyTorch 安装包、下载缓存、临时文件（缓存和安装包装好以后可以删） |
| `.venv\`、`ai-env\` | 两个 Python 环境 |

Python 本身是你装的。`开机自启.bat` 会在 Windows 任务计划里加两个登录时启动的任务，`取消开机自启.bat` 删掉它们。

下载的东西加起来约 11GB：
- `ai-env\`：约 5GB
- `models\`：约 8GB，其中底座和嵌入模型 6GB、Kev 权重 2GB
- `tools\wheels\`：约 3GB，装好以后可以删

**想让它更懂你：** 改 `memory\提示词\人设.md`，写上怎么称呼你、平时做什么、电脑配置，它回答时会参考。这个文件只在你自己电脑上，不会上传。
