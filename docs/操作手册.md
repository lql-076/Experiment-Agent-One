# 操作手册

> 最后核对：v1.8.9（2026-10-28）。界面里每个设置下面都有一行小字说明，这里讲的是"整体怎么用"。

## 一、第一次装

1. **装 Python 3.12。** 安装第一页勾选 *Add python.exe to PATH*。显卡驱动装好就行，Git 不用自己装。
2. **把 Agent 文件夹放好。** 哪个盘都行，路径里最好别带空格，例如 `D:\Agent`。
3. **双击 `启动.bat`。** 第一次会建环境、装依赖，大约 1 分钟（这时有一个黑窗口显示进度），装完自动打开界面，黑窗口自己关掉。以后双击就直接出界面，不留黑窗口；起不来会弹框说原因。
4. **填 DeepSeek Key。** 设置 › 云端，填好点「保存」。保存后会自动查这个 Key 能用哪些模型，「模型」一栏变成下拉框，选一个就行。同一页最上面选第三条路「更强的模型」接不接受（见第三节），默认接受。
5. **点「一键补齐」。** 设置 › 整备 最上面。它按顺序装好 6 样东西，一共下载约 11GB：
   1. 便携版 Git
   2. 本地模型环境
   3. 底座和嵌入模型
   4. 启动模型服务
   5. Kev 权重
   6. 硬件监控助手（会弹一次管理员确认，点「是」；以后跟着 Agent 一起起，不再弹，也没有黑窗口）
   - 可以关掉界面，它在后台接着装。
   - 侧栏「后台 › 进展报告」能看到每一步在干什么。
   - 只用点这一次：以后每次启动会自动查一遍，好了的标「已就绪」，不用再点。
6. **接 QQ。** 设置 › QQ 通道，填 AppID 和 AppSecret。用你的 QQ 给机器人发一句话，到 整备 › 绑定你的 QQ 点「是我」，再点「发测试提醒」。
7. **装好以后：**
   - 设置 › 提醒：自带一条示例提醒（默认关着），改成你要的时间和内容再打开。
   - 大脑 › 决策脑：运行中文实测，按两票的准确率自动分配权重。
   - 可选：设置 › 自动化 打开「开机自启」，以后登录 Windows 自动启动 Agent（硬件监控助手开关开着的话跟着一起起）。不要管理员；`开机自启.bat` 留着备用。
   - 可选：要给视频配音，设置 › 本地模型 点「安装配音」（见第四节「配音页怎么用」）。

从别的 agent 换过来的话，等这边的提醒测试通过了再关旧的。

## 二、每天怎么用

| 想做什么 | 怎么做 |
| --- | --- |
| 打开 | 双击 `启动.bat`。一打开就是「对话」页，不留黑窗口。已经在运行的话，它会直接把界面拿出来 |
| 看它现在哪些能用、哪些缺着 | 「对话」页右边的「Agent 状态」：中间大环是几项能用，链路图看一条消息能不能走通（流动的线是通的，红虚线是断了），每项一张卡片，红的点按钮直接去补。「总览」上那张卡片一格一个图标 |
| 收起到任务栏 | 侧栏「收起」 |
| 关掉窗口，但提醒和 QQ 照常 | 侧栏「关闭」→「关掉窗口」。再打开：双击 `启动.bat` |
| 完全退出 | 侧栏「关闭」→「退出 Agent」。模型服务、Kev、游戏内显示、硬件监控助手一起停 |
| 不想每次都问 | 关闭菜单里勾「记住」，或者 设置 › 外观 ›「点侧栏『关闭』时」 |
| 全屏 / 窗口 | 侧栏「全屏」。窗口模式下拖顶栏移动；拖到屏幕顶部最大化，拖到两边半屏；四边四角能改大小；双击顶栏最大化 |
| 横屏 / 竖屏 | 默认按窗口比例自动切换；侧栏「自动」可以固定横屏或竖屏 |
| 常驻屏（大时钟 + 硬件） | 侧栏「常驻」，或者 5 分钟不动自动进入（设置 › 自动化）。按 Esc 或点一下回来。后台在装东西、下模型、生成配音时，硬件格子下面多一条进度条 |
| 换风格 | 侧栏「风格」，或者 设置 › 外观。三套风格的手感不一样，见下面第五节 |
| 玩游戏时看帧数和温度 | 先在 设置 › 硬件监控 打开硬件监控助手；再到 设置 › 游戏内显示 打开，选好显示哪几项、放哪个角、什么时候显示（只在玩游戏时 / 一直显示）。游戏里按 Ctrl + Alt + F10 藏起来 / 显示。游戏要用「无边框」或「窗口化」模式。把游戏加加之类认成了游戏：同一页「游戏识别」里点「这不是游戏」 |

## 三、和它说话

在界面「对话」页（侧栏第一个）最下面的输入框里发，Enter 发送、Shift + Enter 换行；也可以在 QQ 里发。两边走的是同一条路，QQ 上的对话也会出现在「对话」页。

每条回复下面有一行小字：交给谁、把握高不高、联网查了几次、花了多少钱。点它，右边会显示这条是怎么处理的：分数、为什么、每一步、查过的网页。判错了也在那里改：
- **记一下应该交给谁**：以后照这个判；
- **换它重做**：「交给本地小脑 / DeepSeek / 更强的模型重做」，马上按你选的再处理一遍（也会记下）。涉及隐私的事交给云端，要再点一次确认才发出本机。

**第三条路「更强的模型」：** 特别难的事（整体架构、长期规划、深度研究），它会写好提示词，让你带去问你能用的最强的 AI——网页 Claude、ChatGPT、Kimi、豆包都行。设置 › 云端 可以改这条路的名字（比如改成「网页 Claude」），也可以选「不接受」：那样难的事也交给 DeepSeek。

| 你说 | 它怎么做 |
| --- | --- |
| "每天晚上十点提醒我吃药"、"半小时后提醒我收衣服" | 程序直接建提醒，不经过模型 |
| 提醒来了以后回"吃了""好了""收到" | 打卡 |
| 回"晚点""等会""20 分钟后" | 顺延 |
| "记住……" | 写进 `memory\记忆\收件箱.md`，每日差事再整理进长期记忆 |
| 样本攒够、它问你要不要训练时，回"开始"或者"等一下" | 记下同意，或者过一阵再问 |
| "帕鲁最近更新了什么"、"显卡现在多少钱"这类要查最新的 | 交 DeepSeek，它自己上网搜、读几个网页再答，末尾带来源链接 |
| "免打扰在哪设置"、"你能做什么"这类问它自己的 | 先查说明书（这份手册和 `docs\AI文档\`），照着说明书答，告诉你在界面哪里点 |
| 其他任何话 | 决策脑打分：本地小脑处理、交 DeepSeek，或者建议你带着提示词去问更强的模型 |

- **隐私内容只在本地处理。** 比如涉及药、医院、病、密码、银行卡，绝不发给云端，也不会拿去联网搜。本地模型没准备好时，它会先记着，等能处理了再通过 QQ 回你。
- **判错了：** 在「对话」页点那条回复下面的小字（或者在「事件」页点开那件事），选它本来应该交给谁。你的纠正立刻变成新判例，下次就判对。
- **QQ 里的回复是纯文字**（QQ 不显示加粗、列表这些格式）；界面上照常显示格式。

| --- | --- |
| 对话 | 左边窄栏和它聊天（一打开就是这页）。右边大块平时是 Agent 状态（一屏放得下，不用滚；地方够就字大、松一点），点回复下面的小字切到「这条怎么处理的」，能换它重做。竖屏时状态在上、对话在下，状态可以「收起」 |

### 配音页怎么用

用的是阿里通义的 Qwen3-TTS 1.7B，在你电脑上生成、不联网，Apache 2.0 许可证，可以商用。**不克隆任何真人的声音。**

1. **第一次先装：** 设置 › 本地模型 最上面「配音」那一块，点「安装配音」。它装一个单独的配音环境（`tts-env`），再从魔搭下两个配音模型（每个 4~5 GB）和一个时间轴对齐模型（约 1.8 GB），一共约 16 GB。以前装过配音的，那一块写着「没装全」，点「接着装」只补对齐模型。可以关掉界面，它在后台接着装，进度在那一块和 后台 › 进展报告 里看；断了再点一次接着下，魔搭下不动就点「改从 hf-mirror 下」。`安装配音.bat` 留着备用，做的事一样。
2. **贴文案。** 默认整段一次念完（语气前后连贯）；空一行算换段，停得久一点。文案框下面能改「句子之间停几秒」「换段停几秒」（默认 0.35、0.7；整段生成时，模型自己停得比这个短才补长）。
3. **选音色：**
   - **预设音色：** 9 个。中文的是 Vivian（明亮的年轻女声）、Serena（温柔的年轻女声）、Uncle_Fu（低沉的成熟男声）、Dylan（北京话男声）、Eric（四川话男声）；还有英文 Ryan、Aiden，日语 Ono_Anna，韩语 Sohee。
   - **描述音色：** 写一段话描述想要的声音（性别、年龄、音色、语速、情绪），配一个随机种子。听着满意就起个名字「存成我的音色」，下次点一下就用。「试同一个人」用这个音色念两段不相干的话，听前后像不像一个人。
   - **语气（可选）：** 一句话，比如「语速稍快，带点兴奋」。
4. **点「生成配音」**，看进度；生成好了在右边试听，点时间轴上的一句就跳到那里。
   - 按钮旁边能选「整段一次生成」（默认，语气连贯；念完才出声音，进度是按上次的速度估的）或「一句一句」（进度准，但每句是分开念的，语气可能不一样）。
   - 每句的时间（字幕）是对齐模型拿音频和原文对出来的，误差几十毫秒；时间前面带 ≈ 的是没对上、估的，做字幕时留意一下。
   - 波形下面那行写着时间轴准不准：绿的「本地对齐，N 句都对上了」可以直接用；**红的「没对齐，是按停顿猜的」**（没装对齐模型、或者在玩游戏让路）可能对不上：装好对齐模型以后点那行后面的**「重新对齐」**，声音不动、不用重新生成、不花钱。
   - 生成完那句「好了：52 秒音频，生成用了 3 分 24 秒（照这个速度，1 分钟音频要 3 分 53 秒）」：括号里是速度，换算成 1 分钟音频要多久。
5. **满意了点「保存」。** 存在 `配音输出\` 里，一次一个文件夹，名字带日期和音色，比如 `2026-10-28_1530_Serena\`，里面四个文件：
   - `….wav`：配音
   - `…_时间轴.json`：每句的开始、结束、原文（做视频时按它对齐字幕和画面）
   - `…_字幕.srt`：同一份时间轴的字幕格式
   - `…_文案.txt`：原文

配音服务用到才启动（第一次要等半分钟到一分钟），闲置 10 分钟自己关掉；在玩游戏、显存被别的程序占了，也会马上关掉把显存还回去，正在生成的会停下。右上角「关掉」可以手动关。

**页面长什么样（v1.8.12）：** 左边文案，中间音色和表达（语气、语速……），右边「生成配音」和波形。生成好的配音画成波形，一段是一句：点哪就从哪播放，**空格键**播放 / 暂停，下面的时间轴跟着亮。

**百炼云端（v1.8.11）：** 标题旁边的开关点「云端」，换成阿里云百炼的千问语音合成（声音比本地好，按字计费，不用显卡，玩游戏时也能生成）。本地的留着当备用，随时点回来。

1. **先填 Key：** 设置 › 云端 最下面「百炼 API Key」，填北京地域的 Key，点「保存」。加密保存在本机，不写日志，导出设置时不包含。
2. **选音色（「音色库」）：** 4 个现成的中文音色（龙安灵心、龙安欢、龙安风悦三个女声，许南川男声），下面是你自己造的。每个旁边有 ▶ 试听，念一句固定的短句；念过的再点不花钱，再点一下停。
3. **自己造一个音色（创建不要钱）：**
   - **设计：** 写一段描述（性别、年龄、音色、语速、情绪、用在哪；下面的灵感词点一下就接上），起个名字，点「设计一个音色」。造好马上放一段试听；百炼审核几秒到一分钟，「审核中」变成能用就能拿来生成。不满意就改描述再设计一个，比着听，不要的点 × 删掉（点两次）。
   - **复刻：** 把 10~20 秒的录音拖进框里（WAV / MP3 / M4A），或者选「用最近生成的配音」（比如先用本地的描述音色念一段）。**勾上「这段声音是我自己的，或者是 AI 生成的」**才能复刻，不复刻别人的声音。录音有杂音就打开「降噪」。
   - 一个百炼账号最多 1000 个，一年没用过的百炼会删掉。在百炼控制台造的，点「同步」拿回来。
4. **表达（可选）：** 语气指令一句话，比如「请用轻松、带点兴奋的语气，语速稍快」；语速、音调、音量拖滑块（双击回到默认）；语言一般选「自动」。文案框上面一排情绪标签，点一下插在光标处：兴奋、严肃、难过、耳语、很慢、很快，笑、叹气（字幕里会去掉）。
5. **读音：** 多音字念错了（比如「重庆」），在「读音」页加一条：重庆 → `chong2 qing4`（拼音后面跟声调数字，轻声写 5）；缩写想换个念法用「替换」：LHY → L H Y。生成时只把这次文案里出现的词发过去。
6. **看预估花费再点「生成配音」：** 贴了文案就显示「约多少计费字符、多少钱」。边念边传回来，进度是真的。超过 2000 字按段落分几块念（同一个音色和语气），拼成一个文件。
7. 生成完和本地一样：试听、点波形或时间轴跳、「保存」出同样 4 个文件。时间轴用百炼返回的每个字的时间拼出来；百炼没给就按停顿对齐。波形下面一行写着时间轴准不准（几句是准的、几句是估的）。

只把配音页里的文案、语气（还有你自己选的复刻录音）发给百炼，别的都不发。出错（Key 不对、欠费、限流、断网、文本太长）会写清楚原因，不会一直重试。设置 › 云端 还能改模型名（默认 Plus，别用体验中心默认的 Next）、单价（只用来估算，以百炼账单为准）、一次最多发多少字、接口地址。

### 生图页怎么用

视频窗口每期出一份「生图清单」（Markdown）：这期的视觉方向，加上每张图的文件名（比如 `img01_重点_地铁站.png`）、用在哪一段、比例、透明背景开不开、提示词。以前要一条一条复制去生成、再一张张按文件名存；现在这一页一次出完。用的是 API易（中转站）的 GPT Image 2.5。

1. **先填 Key：** 设置 › 云端 最下面「API易 Key」，填 API易 控制台「令牌」里的 Key（sk- 开头），点「保存」。加密保存在本机，不写日志，导出设置时不包含。
2. **上传清单：** 把 .md 文件拖到生图页上（任何地方都行），或者点「选文件」「粘贴」。上面一条工作流：生图清单 → 视觉方向 → 模型 → 出图 → 生图输出；下面一格一张图。清单里有没写全的（没写比例、透明背景、提示词），「生图清单」那块写着「N 处没认全」，在卡片上补上就行。
3. **看一眼、改一改（可选）：** 每张卡片能改比例（10 种）、透明背景开 / 不开、提示词（改过的标「改过」）。
   - 「视觉方向」那块两个开关：「拼进每条提示词」默认关（正本要求每条提示词里已经写了画风）；「加一句「不要文字」」默认开（图里不放字，AI 画的字容易乱码）。
   - 「模型」那块：GPT Image 2.5 Flare（默认，最快）/ Sunburst（细节更好）/ All（按次 $0.025，不认比例和画质，透明背景不稳）；画质「草稿 / 标准 / 精细」（精细贵 4 倍，先用草稿看构图也行）；尺寸 2K / 1K（16:9 是 2048×1152 / 1536×864）。
   - 「出图」那块写着全部出一遍大概多少钱。
4. **点「全部生成」：** 同时出 3 张（设置里能改），线上在流，卡片上有秒数。透明背景开的会真的出透明 PNG（预览垫棋盘格，标「透明 ✓」；没透明会提醒）。点图看大图，Esc 关。
   - 没出来的那张（审核没过、超时……）写着原因，改一改点「重生成」；或者点「只补没出的」。Key 不对、余额不够会整批停下，不白发。
   - 「停下」：没开始的不出了，正在出的出完（断开的话 API易 照样计费、图却丢了）。
5. **拿图：** 存在 `生图输出\日期_清单名\`，文件名就是清单里写的；「打开文件夹」直接打开。「打包 zip」把这份清单的图打成一个压缩包（放在文件夹旁边），直接发给视频窗口。重生成过的旧图挪进同一个文件夹的 `旧版\`，不删。文件夹里还有 `生图清单.md`（清单原文）和 `生图记录.json`（每张实际发出去的提示词、尺寸、用时、花费）。

只把清单里的提示词（你改过的就用改过的）发给 API易，别的都不发。清单关了 Agent 再开还在；重新上传同一份清单，已经出好的图认得出来，「只补没出的」只补缺的。花费按 API易 返回的用量估，以 API易 账单为准。

## 五、三套风格的手感

| 风格 | 手感 |
| --- | --- |
| 星云 | 漂浮：滚轮带惯性；背景和标题有视差；卡片滚进视野时从模糊里浮上来；卡片跟着鼠标微微倾斜 |
| 深海 | 精确：标题吸顶并收窄；顶部滚动进度线和"第几块"；滚动停下对齐到卡片；悬停出现瞄准框 |
| 绛焰 | 杂志：大脑页、主题卡排成横条，滚轮往下 = 往右翻一张，也能按住拖；揭幕式出场；标题后的大字随滚动移动；数字跳动；按钮会被鼠标吸过去 |

嫌晃就到 设置 › 外观 › 动效 选「减弱」或「关闭」。

## 六、更新到新版本

1. 把新压缩包解压到**原来的** Agent 文件夹，选「替换」。压缩包可以是作者发的，也可以从 GitHub 仓库 Code → Download ZIP 下载；后者解压出来的文件夹名不一样，把里面的东西拷进原来的 Agent 文件夹替换就行。
2. 双击 `启动.bat`。依赖有变化会自动补装。

**旧压缩包可以删，Agent 文件夹别删。** 下好的约 11GB、设置和 Key、记忆都在文件夹里，压缩包里没有。删了文件夹就要全部重下、重填。

## 七、出问题怎么办

| 现象 | 先看哪里 |
| --- | --- |
| 界面打不开 | 有没有弹框说原因；`data\logs\backend.log` 最后几行；想在黑窗口里看输出：在 Agent 文件夹地址栏输入 cmd 回车，运行 `启动.bat 看日志`；或者 设置 › 外观 › 打开方式 改成 Edge |
| 一键补齐某步失败或像卡住了 | 侧栏「后台 › 进展报告」看它最后在干什么；30 秒没动静进度条会标「可能卡住」；原始日志在 `data\logs\setup_*.log` |
| 本地模型服务起不来 | 后台 › 模型服务 那个日志（`data\logs\model_server.log`）最后几行 |
| Kev 起不来 | `data\logs\kev.log`；下不动的话可以先在 设置 › 本地模型 把 Kev 关掉。权重下完一次就不会再下：整备里 Kev 那项显示「权重已下载 · 用到才启动」就对了 |
| 整备里缺的项 | 开机头 2 分钟里没准备好的显示「启动中」，会自己变绿，不用管；过了 2 分钟还缺的，点「一键补齐」；还不行就点那一项的「问 DeepSeek」。每一项什么时候缺了、为什么，`data\logs\backend.log` 里搜「自检：」 |
| Agent 自己没了（没点退出） | 下次启动时进展报告里会写一句上次是怎么停的；底层崩溃的记录在 `data\logs\crash.log`。注意：任务管理器里的 Python 进程就是 Agent，别误结束 |
| QQ 收不到提醒 | 整备 › 测试主动提醒；QQ 里是不是关了"允许主动发送"（关了的话会改成电脑弹窗 + 界面卡片） |
| CPU 温度、游戏帧数不显示 | 设置 › 硬件监控 的助手开没开、在不在跑；CPU 温度、功耗显示"—"是读不到，要装一次 PawnIO 驱动（pawnio.eu），装完重启电脑；游戏帧数只支持 DirectX 10/11/12 |
| 不在玩游戏，帧数小框却出来了 | 设置 › 游戏内显示 › 游戏识别 看是哪个程序被当成了游戏，点「这不是游戏」 |
| 游戏里看不到帧数小框 | 游戏的显示模式改成「无边框」或「窗口化」（独占全屏会把它盖住）；「只在玩游戏时显示」要硬件监控助手开着才读得到帧数，可以先改成「一直显示」试试；按一下 Ctrl + Alt + F10 看是不是被藏起来了；还不行看 `data\logs\osd.log`，或者看 Agent 状态里「游戏内显示」那一行 |
| 配音的时间轴、字幕对不上 | 看波形下面那行：绿的（百炼逐字时间戳 / 本地对齐）是准的；标黄的是有几句估的；**标红的是按停顿猜的**——到 设置 › 本地模型 把「时间轴对齐模型」装上，回配音页点「重新对齐」（不用重新生成、不花钱）。自己设计、复刻的音色百炼不给每个字的时间，全靠本地对齐。还不对就把那次的文件夹和 `data\tts\last_bailian.json`（百炼返回的时间戳，不含 Key）、`data\logs\tts.log` 发给 Claude 查 |
| 生图出不来 | 卡片上写着原因：Key 不对就到 设置 › 云端 重填 API易 Key；余额不够去 API易 控制台充值；「内容审核没过」就改改提示词（别写真人、品牌）；「太快了，被限流」就把 设置 › 云端「同时出几张」调小。清单认不全：把那份 .md 发给 Claude 看 |
| 配音（百炼云端）生成不了 | 「生成」那块写着原因：Key 不对就到 设置 › 云端 重填北京地域的 Key；欠费就去百炼控制台充值；报文本太长就把 设置 › 云端「一次最多发多少字」调小；连不上先看网。实在不行点回「本地 Qwen3-TTS」 |
| 配音生成不了 | 配音页上面写着缺什么（没装就到 设置 › 本地模型 点「安装配音」；装的原始输出在 `data\logs\setup_tts.log`）；配音服务的日志在 `data\logs\tts.log`（后台页也能看）；在玩游戏时不生成，关了游戏再点 |
| 窗口在副屏上显示不全 | 截图到 GitHub 提 Issue；临时可以换成 设置 › 外观 › 打开方式 › Edge |

## 八、文件都在哪

全部在 Agent 文件夹里，不往 C 盘用户目录写：

| 位置 | 是什么 |
| --- | --- |
| `app\` | 后端代码 |
| `ui\` | 界面：`index.html`、`css\`、`js\`（按页面分文件）、`themes\`（一个 .css 一套风格） |
| `scripts\` | 安装、下载用的脚本 |
| `docs\` | 这些说明文档；`docs\AI文档\` 是架构说明的文字版，给 AI 看 |
| `kev\` | 决策脑 Kev 的源码（Apache-2.0） |
| `models\` | 底座、嵌入模型、小脑、Kev 权重、配音模型（`models\tts\`） |
| `配音输出\` | 保存的配音，一次一个文件夹 |
| `生图输出\` | 生图页出的图，一份清单一个文件夹 |
| `memory\` | 记忆、技能、提示词、从更强的模型带回的总结（中文 Markdown，git 记录改动） |
| `training\` | 慢成长的样本 |
| `data\` | 设置、数据库、日志、加密的密钥 |
| `tools\` | 便携版 Git、PyTorch 安装包、下载缓存、临时文件（缓存和安装包装好以后可以删） |
| `.venv\`、`ai-env\`、`tts-env\` | 三个 Python 环境（后端、本地模型、配音；配音的是装了配音才有） |

Python 本身是你装的。开机自启平时在 设置 › 自动化 开关（写的是你这个账号的启动项）；`开机自启.bat` 留着备用，它在 Windows 任务计划里加一个登录时启动的任务，`取消开机自启.bat` 把任务和启动项都删掉。

下载的东西加起来约 11GB：
- `ai-env\`：约 5GB
- `models\`：约 8GB，其中底座和嵌入模型 6GB、Kev 权重 2GB
- `tools\wheels\`：约 3GB，装好以后可以删
- 装了配音再加：`tts-env\` 约 5GB、`models\tts\` 约 9GB

**想让它更懂你：** 改 `memory\提示词\人设.md`，写上怎么称呼你、平时做什么、电脑配置，它回答时会参考。这个文件只在你自己电脑上，不会上传。
