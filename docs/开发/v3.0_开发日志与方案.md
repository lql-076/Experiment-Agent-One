### 做的时候踩到的坑（接手的人留意）

- **沙箱的时钟只在有命令在跑的时候走。** 用 `&` 丢到后台的 `dev/check.sh` 不会自己跑完：要开一个前台命令等着它（`timeout 570 bash -c 'until grep -q "^exit " 日志; do sleep 10; done'`，一次最多 10 分钟，多等几次）。
- `dev/serve.sh stop` 以前会留下假配音服务的孤儿进程占着端口：现在 stop 里按本项目的脚本路径把它停掉了。
- 面板的切角不能直接用 `clip-path` 裁面板本身：里面弹出来的「细节」会被切掉。现在框画在两层伪元素上。
- 提示条原来在右下角，会挡住指令条：挪到右上角了（竖屏在指令条上面）。
- Claude Code 如果是 npm 装的（`claude.cmd`），参数要过 cmd.exe，带换行的参数会被截断：这种情况把 `--append-system-prompt` 的内容压成一行（`ccode.command()`）。真机没试过。
