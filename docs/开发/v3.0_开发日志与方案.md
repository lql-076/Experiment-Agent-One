## 三、方案

### 3.1 Agent 能力（后端基本写完，见第四节）

| 做什么 | 在哪 | 要点 |
|---|---|---|
| 计划、喊停、插话、预算、上下文裁剪 | `app/agentkit.py`、`app/websearch.py`（answer_with_tools） | 每件事一个开关 `agentkit.CTRL[事件号]`；`update_plan` 工具把计划存进 `events.plan`；`POST /api/events/{id}/stop`、`/say`；一件事最多 `agSteps`（120）步、`agBudget`（¥5，0 = 不限）；老的工具输出自动缩短 |
| 新工具 | `app/agentkit.py` | `look`（看图 / 看视频里几秒的画面）、`media_info`、`download_file`（只许公网）、`read_skill`、`make_voice`（本地配音；云端要开关）、`make_image`（花钱，默认关，一件事最多 `agImageMax` 张）、`make_music`（配乐配好了才给） |
| 工具箱 | `toolbox/` → 每次用工作区前同步到 `工作区\工具箱\` | `录网页.py`（网页动画一帧帧录成视频，接管页面时间）、`合成.py`（画面 + 配音 + 配乐压低 + 字幕）、`口型.py`（差分图按配音切嘴型） |
| 技能 | `skills/*.md`（自带）+ `工作区\技能\*.md`（他或 Agent 自己写的） | 开头两行「用在：」「触发：正则」；对上触发词就把全文带进说明；`read_skill` 工具 |
| Claude Code 引擎 | `app/ccode.py` | `claude -p --output-format stream-json --verbose --permission-mode acceptEdits --allowedTools …`，cwd = 工作区，事情从标准输入给；一行行读 JSON 变成事件的每一步，TodoWrite = 计划；记会话号，「继续」用 `--resume`。**默认关**（`ccOn`），`ccAuto` 开着时工作区的活自动交给它；出不来退回 DeepSeek |
| 开关都算「给 Agent 加权限」 | `settings.PERM` | `agDownload agVoice agVoiceCloud agImage agMusic ccOn` 只能走 `PUT /api/agent/caps`（记动作日志），通用的改设置改不了 |

### 3.3 语音对话

- 听写：**Qwen3-ASR-0.6B**，跑在现有的配音服务里（`app/tts_server.py` 加了 `/asr`；tts-env 里本来就有 `qwen-asr` 包，只差模型：`scripts/install_tts.py --asr`，界面上「下载听写模型」= `POST /api/tts/install {asr:true}`）。
- 说话：**Breeze TTS 2**（官方只支持 Linux，约 7.7 GB 显存，权重非商用）。Agent 不装它，只连接口（`voiceUrl`，默认 `http://127.0.0.1:8093`）：`POST /v1/audio/speech`（表单 text、instruction / ref_audio + ref_text、cfg_scale、seed）→ 24 kHz 单声道 16 位 PCM 流。填了 `voiceDir`（或 `voiceCmd`）Agent 自己启动、闲置关、让路关。
- Breeze 没配好时：用现有的本地配音（Qwen3-TTS）出声（**待做**：`voice.py` 里的退路）。
- 界面：麦克风按钮（按住说 / 免提）、录音在界面里用 WebAudio 采成 16 kHz WAV → `/api/voice/asr` → 文字照常发 → 回复 `/api/voice/speak` 流式播放。**待做**。
- 它念的不进要挣钱的视频（规矩写在 `voice.py` 开头）。
