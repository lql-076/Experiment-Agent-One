# 更新记录

每一版改了什么。更新方法：新压缩包解压到原来的 Agent 文件夹，选「替换」，再双击 `启动.bat`。

## v1.4.1（2026-10-22）

- **代码放上了 GitHub（公开仓库），从这一版起每一版都提交上去、打标签：**
  - 只上传代码和文档；
  - 设置、密钥、数据库、日志、记忆、人设、聊天和提醒记录、训练样本、模型，都由 `.gitignore` 挡在外面；打包时再按禁止清单查一遍。
- **测试工具放进了 `dev\`：** 假服务、测试后端、界面冒烟测试、一条命令的回归 `dev/check.sh`、打包脚本，还有给新窗口的交接说明。换一个 Claude 窗口也能接着改、接着测。
- **电脑配置不再写死：** CPU 型号从注册表读，显卡和显存从驱动读；让 DeepSeek 看安装日志时，告诉它的配置也是实际读出来的。
- **默认人设去掉了个人信息。** 你电脑上已有的 `memory\提示词\人设.md` 不受影响。
- 项目首页（README）改成对外介绍：做什么、怎么想的、做到哪、借鉴了谁。原来的使用说明都在 `docs\操作手册.md` 里。

## v1.4.0（2026-10-21）

- **侧栏加了「关闭」：**
  - 弹出两个选择："关掉窗口"（后台继续，提醒和 QQ 照常）和"退出 Agent"（全部停掉，黑窗口也关）。
  - 可以勾「记住」，设置 › 外观 能改回来。
- **双击 `启动.bat` 时 Agent 已经在跑：** 直接把界面拿出来，多出来的黑窗口自己关掉。
- **新增说明文档**（`docs\`，界面侧栏「说明」能看）：
  - 操作手册；
  - 架构总览（带一张按实时状态上色的架构图，以及和「最终版架构」的逐条对照）；
  - 13 篇各功能的架构；
  - 本更新记录。
- **新增「当前结构（自动生成）」：** 后端每次启动按代码重写，内容是模块、接口、后台任务、设置项、主题、端口、数据文件，所以不会过时。

## v1.3.1（2026-10-21）

- API Key 输入框里只留一个"眼睛"（去掉 Edge 自带的那个）。
- **模型名不再写死：**
  - 「获取模型列表」用你的 Key 从官方查能用的模型，下拉框选，也能手动填。
  - 保存 Key 时自动查一次。
- 修好：深海风格下，整备页滚到顶会被弹回去一截。原因是滚动吸附作用在了一直在变的设置页上。

## v1.3（2026-10-20）

- 竖屏「后台」三块一屏放下，进展报告自己在里面滚。
- 修：竖屏副屏上全屏右边一截跑到屏幕外。窗口最小尺寸改成按当前屏幕的缩放算，全屏时不限制。
- 检查下载的 PyTorch 时有进度条了（以前一直显示 0%）。
- **三套风格的交互手感：**
  - 星云：漂浮，惯性、视差、倾斜。
  - 深海：精确，吸顶、进度线、吸附、瞄准框。
  - 绛焰：杂志，横向翻卡片、揭幕出场、背景大字、数字跳动、磁吸按钮。

## v1.2.1（2026-10-20）

- 修：切页时旧页面要等新页面出来才消失。
