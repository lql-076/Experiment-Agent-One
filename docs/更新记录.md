# 更新记录

每一版改了什么。更新方法：新压缩包解压到原来的 Agent 文件夹，选「替换」，再双击 `启动.bat`。

## v1.9.0（2026-10-24）

- **接 Obsidian（设置 › Obsidian 笔记）。** 两个库都能接：一个只读（E 盘的一律只读），一个能写。
  - **读笔记回答问题：** 问到你写过、记过的东西，先查笔记再答，最后写用了哪篇。DeepSeek 还能自己再查、读整篇。
  - **私人文件夹只给本地小脑：** 在设置里点选私人文件夹（笔记顶部写 `私人: true` 或者带 `#私人` 标签的也算）。私人笔记不发给 DeepSeek；用到私人笔记的事改交本地小脑。
  - **往库里写：** 「存到笔记：……」「把刚才的回答存到笔记」写进能写的库的「Agent 收件箱」，不改你自己的笔记；写错了在 报告 › 改动 里撤销（挪进「已撤销」，不删）。
  - **每天帮你整理：** 每日差事写一篇「每日整理」放进收件箱：今天聊了什么、可能前后矛盾的地方（比如主角的等级两处写得不一样）、可以加的 `[[链接]]`。只列建议。
  - **记忆放进库里：** 设置页一个按钮，把 Agent 的记忆复制进库的「Agent 记忆」文件夹，在 Obsidian 里就能看、能改；原来的文件夹改名留着。
  - 笔记改了，每分钟自动更新一次索引。索引存在 Agent 自己的 data 里，不往库里放任何东西。
- **修：「记住……」「……提醒我……」、回提醒的"吃了""晚点"在对话里会出错（从 v1.7.0 起）。** 这几种不经过模型的快捷处理里有个函数自己调自己，一调就报错。现在好了，测试里也加上了。
- Agent 状态的「大脑」组加了一项「Obsidian 笔记」。

## v1.8.2（2026-10-24）

- **修：竖屏时对话页上面的 Agent 状态要用滚轮翻。** 字调大、或者竖屏窗口比较小的时候放不下。现在：

  - 放不下时多分几列（每列窄一点），再不行收成最紧的样子（藏掉提醒那条专线、每项更矮）；
  - 竖屏时健康环和链路图尽量并排，不再上下摞着。
- 卡片窄的时候，名字自己缩短，「去补齐」这类按钮不再挤出卡片。

## v1.8.1（2026-10-24）

- **整备改回上下滚动的样子。** 一屏放下的规矩只管"一眼看"的页（对话页的 Agent 状态、总览、常驻屏）；整备、设置这种要动手操作的页可以滚。
- **启动后不用再点一键补齐：**
  - 一键补齐的 6 步按启动自检的结果标状态：已经好了的标「已就绪」，本地模型服务和硬件监控助手标「自动启动中」（它们自己会起来），只有真缺东西（要下载、要你确认一次管理员）的才标「要补」。
  - 都齐了按钮就是「都齐了 · 再跑一遍」，缺几项是「补齐缺的 N 项」。
  - 模型服务、Kev、硬件监控助手、QQ 这几项后台每隔一会儿重查，起来了整备上自己变，不用点重新自检。
- **修：Kev-0.8B 每次都要"重新下载"：** 以前整备只看 Kev 在不在线，它是用到才启动的，所以每次都显示要下载，一键补齐也每次去拉它。现在看本机有没有权重（Kev 和它的底座都要在、没有下了一半的文件），有就是「已就绪 · 用到才启动」。成功启动过一次以后，启动 Kev 不再联网，不会再下载。
- **修：硬件监控助手明明在跑，整备显示缺失：** 自检比助手先跑完了。现在开关开着时自检会等助手一会儿，助手起来后整备也会自己更新。
- **对话页：** 聊天窄栏再收窄一点（窗口宽度的 19% 左右），Agent 状态放大：地方够就字大一号、留白多、每项那句话显示出来；只有放不下才一级一级收紧。几列一样高，铺满到底。卡片窄的时候不显示名字后面的小字，免得一排省略号。
- **总览：** Agent 状态那张卡变宽，格子更大，不再挤在一起。
- **游戏内显示：** 可以横着排成一行（设置 › 游戏内显示 › 排列），位置加了「顶部居中」「底部居中」，放在屏幕上边正中间不挡左上角的小地图。预览跟着变。

## v1.8.0（2026-10-23）

- **一页一屏放下，不用滚轮翻：** 整备、设置的每个分区、大脑、报告、常驻屏、对话页的 Agent 状态，横屏竖屏都在一屏里看全。东西多的页面分左右两栏；Agent 状态会按窗口宽度自动分几列、放不下就自动变紧凑。只有聊天记录、事件列表、日志、说明文档这种本来就是长列表的地方还能滚。
- **没有黑窗口了：**
  - 双击 `启动.bat` 直接出界面，黑窗口不留（第一次装依赖时会看到进度，装完自己关）。起不来会弹框说原因。想看输出排查问题：`启动.bat 看日志`。
  - 硬件监控助手也没有黑窗口，说的话写进 `data\logs\hw_helper.log`（后台页能看）。
- **硬件监控助手有开关了（设置 › 硬件监控）：** 打开后跟着 Agent 一起起、一起退。第一次弹一次管理员确认，之后用 Windows 计划任务提权启动，不再弹。`开机自启.bat` 不再单独起它。
- **第三条路改名「更强的模型」，你说了算：**
  - 设置 › 云端 最上面：接受 / 不接受。不接受的话，难的事也交给 DeepSeek。名字可以改（比如「网页 Claude」），提示词开头也能改。
  - **换它重做：** 每条回复的「这条怎么处理的」里，「交给本地小脑 / DeepSeek / 更强的模型重做」，马上按你选的再处理一遍，同时记一次纠正。涉及隐私的事换到云端，要再点一次确认才发出本机。
- **修：CPU 温度、功耗、频率显示 0：**
  - 频率改用 Windows 性能计数器读实时频率（以前读的是固定值或 0）。
  - 温度、功耗读到 0 就当"读不到"显示"—"，不再显示 0。要读到得装一次 PawnIO 驱动（pawnio.eu），装完重启电脑。
- **修：开着游戏加加，帧数小框就出来：** 游戏加加、浏览器、聊天软件、播放器、壁纸、OBS、显卡覆盖层这些不再当成游戏；只在游戏是前台窗口时才显示。还认错的话：设置 › 游戏内显示 › 游戏识别，点「这不是游戏」。
- **修：Kev 权重下载失败（hf-mirror 401）：** 关掉了 Hugging Face 的 Xet 下载方式，镜像站支持。更新后在整备页点一次「继续补齐」。

## v1.7.0（2026-10-23）

先查了做 AI 助手界面的几条共识：聊天和执行过程分开放、状态一直看得见、解释按需展开、用了哪些工具要写出来、出错时给下一步。照着改的：

- **新增「对话」页，侧栏第一个，一打开就是它：**
  - 中间只放你和它的一来一回，QQ 上的对话也在这里；回复按 Markdown 显示，不再冒出星号。
  - 每条回复下面一行小字：交给谁 · 把握高 / 一般 / 低 · 联网几搜几读 · 花了多少 · 用了几秒。点它，右边显示「这条怎么处理的」：分数、为什么、每一步、查过的网页，还能直接纠正。
  - 处理中实时显示到了哪一步："DeepSeek 正在想……""正在联网搜索「……」""正在读网页……"。
  - 出了问题的回复（没填 Key、余额不足、本地模型没准备好、搜索次数用完）下面直接给按钮。
  - Enter 发送，Shift + Enter 换行。
- **Agent 状态，一目了然：** 嵌入模型、Kev、底座、每个小脑、攒样本的新类别、DeepSeek、联网搜索、QQ、提醒、后台程序、游戏内显示、记忆索引，每项一个状态灯（正常 / 闲着 / 要注意 / 缺了 / 没开），缺了的点按钮直接去补。对话页右边一份，总览上一张卡片。
- **总览：** 「本地处理比例」「整备」两张小卡换成 Agent 状态卡片。
- **修：** 总览上今日分流、最近事件这几张悬停时不浮起来；深海风格悬停时四个角的瞄准框闪一下就没了（瞄准框伸到卡片外面，被裁掉了，现在改成在卡片里面收拢）。
- **新增「游戏内显示」（设置 › 游戏内显示）：**
  - 像游戏加加那样在游戏画面一角显示帧数、1% 低帧、CPU、显卡、显存、内存、整机功耗、时间。
  - 能选显示哪几项（带实时预览）、位置、哪块屏幕、字号、透明度、只在玩游戏时显示还是一直显示；快捷键 Ctrl + Alt + F10 藏起来 / 显示。
  - 单独的小窗，鼠标点得穿、不抢焦点、不注入游戏。只对「无边框」和「窗口化」的游戏有效。
- **QQ 的回复改成纯文字**，不带 Markdown 符号。
- 事件页不再放输入框（在对话页发），回复也按 Markdown 显示。

## v1.6.0（2026-10-23）

- **联网搜索（DeepSeek 自研搜索引擎，用同一个 Key）：**
  - 交给 DeepSeek 的事，它可以自己决定要不要上网搜、读哪几个网页，回答末尾带来源链接。
  - 判给本地小脑、但要查最新信息的（"最新""最近更新""价格""新闻""天气"……），改交 DeepSeek 联网。
  - 隐私的事不搜；发出去的每个搜索词、网址再过一遍隐私名单。
  - 设置 › 云端：开关、每天最多搜几次（默认 200）、一个问题最多查几轮（默认 4）、「测试一下」，还能看到今天和这个月搜了几次、花了多少。
  - 每次约 5 厘钱，没结果不收钱；记进花费，余额和报告里都算上。事件里能看到搜了什么、读了哪页。
  - 思考模式带工具时把 `reasoning_content` 原样传回去；万一官方拒了，自动改成不思考再答。
- **它会读自己的说明书了：** 问"免打扰在哪设置""你能做什么"这类问题时，先从操作手册和 `docs\AI文档\` 里找最相关的几段，照着说明书回答，告诉你在界面哪里点。
- **系统提示里带上现在的日期和时间**（本地小脑和 DeepSeek 都是），问"今天几号""周几"不会答错。
- 联网查过的回答存成训练样本时标上 `web`，以后训练可以区别对待。
- 架构图：总览加了「回答前查资料」一支；DeepSeek 那篇加了联网搜索；决策脑、记忆、安全线几篇同步更新。总览对照表里"联网搜索"从 ⬜ 变成 ✅。
